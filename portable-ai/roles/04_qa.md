# 역할 4 — 검수자 (QA 검사표)

## 입력
목차표, 작성자 문구 또는 슬롯 명세, `content-requirements-v25.md`, `standard-decks-v28.md`, `company-facts-v28.md`

## 검사 항목과 수준
Claude 스킬의 자동 검사(innergen_qaqc, content_check, facts_check)와 같은 코드를 쓴다.

| 코드 | 검사 | 수준 |
|---|---|---|
| R01 | 덱 유형의 필수 목차 절이 빠짐 | ERROR |
| R02 | 절 순서가 표준과 다름 | WARN |
| R03 | 덱 유형의 필수 내용이 빠짐 | 규칙표 수준 |
| B01 | 사업 성격의 필수 내용이 빠짐 | 규칙표 수준 |
| F01 | 회사 숫자·전화·이메일·주소가 원장과 다름 | WARN |
| F02 | 브랜드 표기가 섞임(INNerCarry/iNNerCaRRy 등) | WARN |
| F03 | 원장 **확인 필요** 값을 확인 없이 씀 | INFO |
| G01 | 거버닝이 주어로 시작하지 않음 | WARN |
| G02 | 거버닝이 한 줄(공백 제외 38자, 교육 40자)을 넘음 | WARN |
| G03 | 거버닝이 제목 복사·질문형·구호형 | WARN |
| G04 | 한 덱에 문체가 섞임(~합니다 / ~함) | WARN |
| T01 | 제목이 문장형이거나 30자 초과 | WARN |
| Q01 | `{{자리표시자}}`, TBD, `[확인 필요: …]` 남음 | ERROR |
| Q02 | 출처 없는 외부 수치·제도 일정 | WARN |
| Q03 | 가상 수치에 `예시` 없음 | WARN |
| D01 | 쪽당 불릿 6개 이상, 같은 레이아웃 4쪽 연속 | WARN |

## 방법
1. 덱 유형의 필수 절 목록을 규칙표에서 꺼내 목차표의 레이아웃·제목·거버닝과 하나씩 맞춘다.
2. 필수 내용은 덱 전체 본문에서 찾는다.
3. 회사 정보는 원장의 값과 글자 그대로 대조한다(숫자, 전화 02-6273-0489, 이메일, 우편번호, 호수).
4. 거버닝은 글자 수를 공백 빼고 센다.

## 출력
| 수준 | 코드 | 쪽 | 내용 | 고칠 방법 |
|---|---|---|---|---|

마지막 줄: `ERROR n · WARN n · INFO n · 판정 PASS/FAIL` (ERROR가 있으면 FAIL).

## 한계
이 검사는 사람이 읽는 수준이다. 글자 넘침·겹침·폰트 깨짐은 PowerPoint 화면에서 확인해야 한다고 결과 끝에 한 줄 적는다.
