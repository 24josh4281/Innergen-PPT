# 예상 결과물 — GPT·Gemini 공통

요청 예: `회사소개서 4장짜리 짧은 버전 만들어줘 (제안서 앞에 붙일 용도)`
아래는 표준 목차(`standard-decks-v28.md` §A 변형)와 회사 원장(`company-facts-v28.md`)으로 나와야 하는 결과의 모범 예시입니다.
실제 답은 표현이 조금 다를 수 있지만 **형식·숫자·연락처는 이와 같아야 정상**입니다.

## 한눈에 보기

| 단계 | 역할 | 결과물 | 사용자가 할 일 |
|---|---|---|---|
| 1 | 기획자 | 본문 구성 프리셋 + 목차표(쪽·레이아웃·제목·거버닝·넣을 내용·거버닝 유형·본문 구성) + 확인 질문 | 목차 확인, 확인 필요 값 답하기 |
| 2 | 작성자 | 쪽별 제목·거버닝 한 줄·본문·출처 | 문구 고칠 곳 말하기 |
| 3 | 디자이너 | 슬롯 명세 JSON | 그대로 복사 |
| 4 | 검수자 | 검사표와 PASS/FAIL | ERROR가 있으면 고쳐 달라고 요청 |
| 5 | (Claude) | 편집 가능한 PPTX | 목차표 + JSON을 Claude innergen-deck 스킬에 붙여 넣기 |

GPT·Gemini는 5단계(PPTX 파일)를 하지 않습니다.

## 1단계 — 기획자: 목차표

계열 `innergen_business`(16:9) · 덱 유형 `company_intro` · 사업 성격 없음 · 4장
본문 구성 프리셋: `balanced` 균형형 (회사소개서 기본값)

| 쪽 | 레이아웃 | 제목 | 거버닝 | 넣을 내용 | 거버닝 유형 | 본문 구성 |
|---|---|---|---|---|---|---|
| 1 | 03e_content_table | 회사 개요 | 이너젠은 2017년 설립 후 5개 분야 기후변화 컨설팅을 수행합니다. | 회사명 ㈜이너젠, 대표자 김성은·손권빈(상근 23명), 설립일 2017년 12월 22일, 위치 서울특별시 용산구 서빙고로 17 센트럴파크타워 704호, 주요 고객 로고(이미지) | 현황·사실 | 표 |
| 2 | s18_keyword_grid | 사업 분야 | 이너젠의 사업은 규제 대응부터 RE100 조달까지 5개 분야를 포괄합니다. | 규제 대응/탄소중립(TMS·ETS·CBAM), 배출권 자산화(규제·자발적), 제품 LCA·환경성 평가, 글로벌 환경 공시(CDP·DJSI·SBTi), RE100 조달(REC·PPA) | 정의·개념 | 도식 |
| 3 | 03f_content_kpi | 핵심 실적 | 이너젠은 2026년 기준 18개+ 업종에서 GHG 규제 대응을 수행했습니다. | 18개+ 업종, 430건+ 인벤토리 구축·규제 대응, 30개+ 방법론, 250만 톤+ 감축실적(확인 필요) | 현황·사실 | 수치 |
| 4 | 03b_content_final | We Do | 이너젠은 과업의 시작부터 끝까지 담당 컨설턴트가 함께할 예정입니다. | 컨설팅의 본질(고객 여건·니즈에 맞춘 실질 가치), 시간·비용·Risk 절약 약속, 연락처 02-6273-0489 · innergen@inng.co.kr | 수행 약속 | 줄글 |

본문 4쪽이 표·도식·수치·줄글로 나뉘어 균형형 기준(한 구성 45% 이하, 3종 이상)을 지키고, 회사소개서에 꼭 필요한 '수행 약속' 거버닝(4쪽)이 들어갑니다.

확인이 필요한 것:
- 감축실적 인정량: 원장 기본값 250만 톤+ (9/16 이너캐리 덱은 300만 톤+). 어느 값을 쓸까요?
- 1쪽 주요 고객 로고 이미지 파일이 필요합니다. 없으면 로고 칸을 빼겠습니다.
- 4장 요청이라 회사소개서 필수 절 '구성 인원'을 뺐습니다. 넣을까요?

→ 여기서 멈추고 확인을 기다립니다.

## 2단계 — 작성자: 쪽별 문구 (1쪽만 예시)

```
P03 · 03f_content_kpi · 현황·사실 · 수치형
제목: 핵심 실적
거버닝: 이너젠은 2026년 기준 18개+ 업종에서 GHG 규제 대응을 수행했습니다.
본문:
- 18개+ | 업종
- 430건+ | 인벤토리 구축 및 규제 대응
- 250만 톤+ | 감축실적 인정 (규제 200만 톤 · 자발적 50만 톤)
출처: 이너젠 내부 실적(’26.9월 기준)
```

## 4단계 — 검수자: 검사표

| 수준 | 코드 | 쪽 | 내용 | 고칠 방법 |
|---|---|---|---|---|
| INFO | R01 | 덱 | 회사소개서 필수 절 '구성 인원' 제외(4장 짧은 버전으로 사용자 승인) | 없음 |
| WARN | D02 | 덱 | 수치형이 25%로 균형형 상한 20%를 넘음 | 4장 덱이라 한 장이 25%다. 그대로 두거나 3쪽을 표형으로 바꿈 |
| INFO | M03 | P04 | 수행 약속 거버닝에 기한·수치 없음 | 회사소개서라 특정 기한이 없으면 그대로 둠 |
| INFO | M05 | P04 | 03b_content_final에는 보통 결론·종합·권고 유형을 씀 | 수행 약속을 유지하거나 결론·종합으로 바꿈 |
| INFO | F03 | P03 | 확인 필요 값 '250만 톤+' 사용 | 사용자 확인 결과를 반영 |

`ERROR 0 · WARN 1 · INFO 4 · 판정 PASS`

검사 코드: R 목차·필수 내용 · B 사업 성격 · F 회사 원장 · M 거버닝 유형(M01–M06) · D 본문 구성(D01 레이아웃 불일치, D02 프리셋 비중, D03 줄글·불릿 분량, D04 같은 구성 연속) · G 거버닝 문장 · T 제목 · Q 잔재·출처
글자 넘침·겹침·폰트는 PowerPoint 화면에서 확인해야 합니다.

이 검사표는 위 목차표를 Claude 스킬 검사 스크립트(content_check, message_check, facts_check)에 실제로 돌린 결과입니다(R01만 사용자 승인을 반영해 ERROR를 INFO로 적음). 사용자 승인 없이 '구성 인원'이 빠졌다면 R01은 ERROR이고 판정은 FAIL입니다. Claude 스킬의 자동 검사도 ERROR로 내므로, 짧은 버전은 PPTX를 만들 때 제외 사유를 함께 알려 줍니다.

## 5단계 — PPTX 만들기 (Claude에서)

Claude 대화에 아래처럼 붙여 넣습니다.

```
이너젠 스타일로 이 목차와 슬롯 명세대로 PPTX 만들어줘.
[1단계 목차표 붙여 넣기]
[3단계 JSON 붙여 넣기]
```

Claude innergen-deck 스킬이 같은 레이아웃 id로 편집 가능한 PPTX를 만들고, 자동 검사(목차·필수 내용·회사 원장 대조) 결과를 함께 줍니다.

## 이너캐리 소개서를 요청하면

`standard-decks-v28.md` §B의 23장 표준 목차(PART 00 회사소개 → PART 01 왜 지금인가 → PART 02 서비스 소개 → PART 03 왜 이너젠인가 → PART 04 도입 효과 → 도입 방식·5단계 → 약속 → Thank you)가 1단계 목차표로 나옵니다.
2028 법정공시 같은 규제 일정에는 "공식 출처 확인 필요" 표시가 붙어야 정상입니다.

## 이상 신호 (이렇게 나오면 다시 요청)

- 전화번호가 02-6273-0489가 아니거나, 감축실적을 확인 없이 300만 톤으로 씀 → "company-facts-v28.md 값으로 다시"
- 목차 확인 없이 문구·JSON까지 한 번에 나옴 → "1단계에서 멈추고 확인받아"
- 거버닝이 두 줄이거나 "~에 대한 내용" 같은 주제 라벨 → "검수자 기준으로 검수해줘"
- 목차표에 거버닝 유형·본문 구성 열이 없거나 열 순서가 다름 → "Claude 개요표 열 순서로 다시"
- 고객사 이름·인물 이름을 지어냄 → 즉시 삭제 요청
