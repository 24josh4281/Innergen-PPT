# Portable capability coverage

This is a portable build of the existing repository chat pipeline, not a
replacement installation of the entire Slide Master repository.

| Repository capability | This package |
|---|---|
| INNerGEN business, lecture and INNerCarry decks | Included: source templates, locks, examples, design rules and editable SVG-to-PPTX engine. |
| Content outline, story, diagram, centering and SVG QA | Included; checker success is distinct from visual rendering. |
| GHG equations and monitoring tables | Included as `reduction-equations`: native Office Math, DOCX/PPTX import/export and verification. |
| Raw PPTX template filling with original design | Requires the full repository `ppt-template-fill` route and its OfficeCLI loop. |
| Strict 1:1 beautification or generic main SVG pipeline | Requires the full repository router and selected owner. This edition follows only the standalone named-style pipeline. |
| Notes, narration, timing and native slide transitions | Requires the full repository native-enhancement/audio route. |
| Custom PowerPoint Masters/Layouts | Portable decks use flat slide structure with editable objects. |
| Browser confirmation UI and live preview | Requires the full repository/local service. |
| AI-generated images | Not bundled; use supplied images and suitable layouts. A separately authorized host capability may be used only when its workflow permits. |
| PowerPoint-exact rendering | Not bundled. Render with an available approved renderer and disclose the actual renderer. |
| Persistent equation web editor or team URL | Not bundled; use chat corrections or the full local repository. |

Use these boundaries when explaining a result. Do not claim all Git features
run inside a chat. Unsupported native operations retain their source deck and
need the full repository rather than silent conversion into a new layout.
