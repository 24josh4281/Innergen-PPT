# INNerGEN Deck — ChatGPT edition

This folder is the claude.ai `innergen-deck` skill repackaged for ChatGPT chat,
Projects and Work (Business/Enterprise) workspaces. ChatGPT runs it inside the
Python tool (data analysis). Read this file first, then follow `SKILL.md`
§1–§7 with the substitutions below. `SKILL.md` stays the authority for every
rule, check and confirmation stop.

Generated by `build_chatgpt_package.py` in the Slide Master repository; edit the
repository source, not an unpacked copy.

## 1. Unpack once per sandbox

The sandbox resets after a period of inactivity. At the start of each turn that
runs a command, check that `/mnt/data/innergen-deck/SKILL.md` exists; if not,
unpack again:

```python
import glob, zipfile
z = sorted(glob.glob("/mnt/data/**/innergen-deck-chatgpt*.zip", recursive=True))
zipfile.ZipFile(z[-1]).extractall("/mnt/data")
```

If no ZIP is visible to the Python tool (project files are not always mounted
there), ask the user to attach `innergen-deck-chatgpt.zip` to this chat and stop.

## 2. Path and command substitutions

| `SKILL.md` says | Use in ChatGPT |
|---|---|
| `${SKILL_DIR}` | `/mnt/data/innergen-deck` |
| `/tmp/<deck>` | `/mnt/data/<deck>` (ASCII folder name) |
| `/mnt/user-data/outputs/<제목>.pptx` | `/mnt/data/<deck>/exports/<제목>.pptx`, then give the link `sandbox:/mnt/data/<deck>/exports/<제목>.pptx` |
| `python3 <script> …` | run it from the Python tool with `subprocess.run([sys.executable, script, …], capture_output=True, text=True)` and print stdout and stderr |
| `pip install` | not available (no internet); report the missing package instead |
| LibreOffice render check | skip when `soffice` is missing; say so in the hand-off |

## 3. Working rhythm

- Follow `SKILL.md` §3: show the outline table, then start drawing in the same
  turn with the recommended defaults; the user revises afterwards. Stop for a
  reply only when the user asked to review the outline first.
- Write pages in batches of four to six per turn and run
  `svg_quality_checker.py` after each batch, so a sandbox reset loses little.
- Export the PPTX after the last batch and again after each requested change;
  name revisions `_ver2`, `_ver3`.
- Never draw slides directly with python-pptx or as images. The editable PPTX
  comes only from `svg_to_pptx.py`.
