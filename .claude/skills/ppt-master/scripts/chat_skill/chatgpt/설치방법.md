# ChatGPT 채팅·Work용 간이 설치 패키지

git이나 Python 설치 없이 ChatGPT 안에서 이너젠·이너캐리 장표(편집 가능한 PPTX)를 만드는 패키지입니다.

## 들어 있는 것

| 파일 | 쓰는 곳 |
|---|---|
| `innergen-deck-chatgpt.zip` | 프로젝트 파일로 올리거나 채팅에 첨부 |
| `chatgpt-project-instructions.txt` | 프로젝트 지침에 붙여 넣기 |

## 준비

- ChatGPT 설정에서 **코드 실행(데이터 분석·Code interpreter)** 이 켜져 있어야 합니다.
- Work(Business·Enterprise) 계정은 관리자가 이 기능을 꺼 두었을 수 있습니다. 꺼져 있으면 관리자에게 요청합니다.

## 설치 (프로젝트 방식, 권장)

1. ChatGPT 왼쪽 메뉴에서 **새 프로젝트**를 만듭니다. 이름 예: `이너젠 장표`.
2. 프로젝트 **지침(Instructions)** 에 `chatgpt-project-instructions.txt` 내용을 그대로 붙여 넣습니다.
3. 프로젝트 **파일**에 `innergen-deck-chatgpt.zip`을 올립니다.
4. 프로젝트 안에서 새 채팅을 열고 요청합니다. 예: "이너캐리 스타일로 CDP 대응 교육 장표 12쪽 만들어줘"

AI가 "ZIP이 보이지 않는다"고 하면 그 채팅에 `innergen-deck-chatgpt.zip`을 한 번 더 첨부합니다.

## 설치 없이 한 번만 쓰기

새 채팅에 ZIP을 첨부하고 지침 내용을 첫 메시지로 붙여 넣은 뒤 요청을 이어서 적습니다.

## 진행 순서

1. AI가 빠진 정보(디자인 유형·보고 형태·사업 유형·분량)를 한 번에 묻습니다.
2. 목차·장별 개요 표를 보여 줍니다. 확인하거나 고칠 점을 답합니다.
3. 장표를 4~6쪽씩 그리고 검사합니다.
4. 다운로드 링크로 PPTX를 받습니다. 고칠 점을 말하면 `_ver2`로 다시 만듭니다.

## 업데이트

## 저장소 설치본과 다른 점

- 확인 화면(브라우저), 라이브 미리보기, AI 이미지 생성, 음성 나레이션은 없습니다.
- PowerPoint로 렌더링해 보는 최종 확인은 하지 않습니다. 받은 PPTX를 열어 확인합니다.
- ChatGPT 작업 공간은 한동안 쓰지 않으면 초기화됩니다. AI가 ZIP을 다시 풀고 이어서 진행합니다. 긴 덱은 중간 결과 PPTX를 먼저 받아 두세요.
