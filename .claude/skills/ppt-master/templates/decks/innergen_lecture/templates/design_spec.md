# 이너젠 소개자료 13:9 템플릿(v4.2 블루) — 디자인 명세

## I. Template Overview

이너젠 회사 소개·교육·강의 자료에서 쓰는 v4.2 블루 화면 계열이다. 표지와 맺음은 짙은 남색 바탕, 본문은 흰 바탕이다. 모든 본문 장표는 **제목(32px) → 거버닝 박스(24px = 18pt, 최대 2줄) → 근거 영역 → (선택) 결론 박스 → 출처 → 푸터** 순서로 읽힌다. 대학 특강·사내 교육·세미나·기후/ESG 교육 같은 발표형·교육형 덱에 쓴다. 보고형(착수·중간·최종)과 제안형의 구성 규칙은 `docs/styles/innergen/innergen-profile-matrix-v16.md`에서 정한다.

테마: mixed(흰 본문, 남색 표지·맺음).

여러 줄 텍스트는 줄마다 `<tspan x dy>`로 나누고 `<text>`에 `data-pptx-preserve-line-breaks="true"`를 붙인다. 붙이지 않으면 PowerPoint가 거버닝 문장을 다시 줄바꿈한다. 좁은 칸은 `data-pptx-text-width`로 글상자 폭을 지정한다.

## IV. Signature Design Elements

- 상단 전폭 3px 블루 선(`#2F62F0`)과 왼쪽 정렬 제목. 제목 오른쪽 위(x 880–992)는 행사·기관 로고 자리로 비워 둔다. 템플릿에는 고객·기관 로고를 고정하지 않는다.
- 거버닝 박스: 48,70 / 944×80, 모서리 5px, `#F3F6FF` 면 + `#DFE7FF` 선. 문장은 x72, 첫 줄 baseline 101, 둘째 줄 133.
- 결론 박스: `#EEF2FF` 면 + 왼쪽 4px 블루 막대 + 24px Bold 남색 문장. 한 장에 하나만.
- 출처: x48, baseline 630, 16px. `출처: 기관, 「보고서명」(발간연월), 기준연도·단위` 형식.
- 푸터: y648 회색 선, 왼쪽 40px 파란 이너젠 로고, 오른쪽 페이지 번호.
- 표지: 남색 바탕, 흰 로고, 56px 제목 아래 120×4 블루 선, `#152959` 핵심 수치 패널(3칸, `#7B9BF7` 구분선).
- 목차: 왼쪽 이소메트릭 일러스트, 오른쪽 5개 목차 행. 장 구분 장표도 같은 Layout을 쓰고 현재 장 행만 슬라이드 위에서 `#EEF2FF` 면과 블루 글자로 강조한다.
- 차트·표: 1순위 `#2F62F0`, 2순위 `#7B9BF7`, 비교·과거 `#94A3B8`, 강조 수치만 `#0B1739` Bold. 차트 위에 한 줄 해석을 거버닝 또는 결론 박스로 둔다.
