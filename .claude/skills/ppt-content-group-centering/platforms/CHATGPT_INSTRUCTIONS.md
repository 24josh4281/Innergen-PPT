# ChatGPT 채팅 · ChatGPT Work 프로젝트 지침 (붙여 넣기용)

사용법: ChatGPT 프로젝트 설정 → 지침(Instructions)에 아래 구분선 안쪽을 그대로 붙여 넣는다.

---

## PPT 정렬 규칙: 상단 쏠림 · 목차 하단 공백 · 본문 하단 공백 방지

PPT·슬라이드를 만들거나 고칠 때 아래 규칙을 항상 지킨다.

**1. 상단 쏠림 금지 (카드 · KPI 상자 · 강조 상자 · 단계 상자)**

- 배경 상자 안의 숫자·제목·설명·아이콘은 하나의 콘텐츠 그룹이다. 그룹 전체를 상자 세로 가운데에 둔다. 요소마다 따로 가운데 정렬하지 않는다.
- 높이는 글상자가 아니라 보이는 글자로 잰다. 한글 줄은 기준선 위 0.78em ~ 아래 0.12em이다.
- 그룹 위치 = 상자 위 + (상자 높이 − 그룹 높이) / 2. 모든 요소를 같은 양만큼 옮긴다. 왼쪽 정렬과 요소 사이 간격은 그대로 둔다.
- 위·아래 여백 차이는 max(6px, 상자 높이의 12%) 이하로 한다. 위·아래 모두 12px 이상 띄운다.
- 제목 + 구분선 1개 + 본문 카드는 제목을 위에 두고, 본문만 구분선 아래 영역 가운데에 둔다.
- 상자 가장자리의 강조선·머리띠·태그는 그룹에서 뺀다.
- 넘치면 줄바꿈 → 간격 → 상자 높이 순으로 조정한다. 글자를 최소 크기보다 줄이지 않는다.

**2. 목차 하단 공백 금지**

- 목차 행 간격 = (목차 영역 높이) / 장 수로 고르게 나눈다.
- 마지막 행과 바닥선 사이 공백은 페이지 높이의 10% 이하로 한다.
- 행이 높으면 쪽별 세부 항목이나 설명 줄을 더해 채운다.
- 목차는 가능하면 표(장 · 제목/내용 · 쪽)로 만들고 셀을 세로 가운데 정렬한다.

**3. 본문 하단 공백 금지**

- 본문 페이지의 마지막 개체 아래부터 출처 줄(없으면 바닥선)까지는 페이지 높이의 6% 이하로 남긴다.
- 채우는 순서: 본문 글자 한 단계 키우기 → 행·카드·이미지 높이 늘리기 → 맺음 메시지 띠(한 줄 요약) 추가.
- 출처 줄은 바닥선 바로 위에 둔다. 출처 줄과 바닥선 사이를 비워 두지 않는다.

**4. 확인과 보고**

- 결과를 렌더 이미지로 보고 위 세 가지를 확인한다.
- 보정 수, 남은 항목, 렌더 확인 여부를 따로 적는다. 확인 못 했으면 "검증 미수행"이라고 쓴다.
- python-pptx를 쓸 때 글상자마다 `vertical_anchor=MIDDLE`만 거는 것으로는 해결되지 않는다. 그룹 전체의 y를 계산해 옮긴다.
