# 이너젠 보고 도표 편집기

일정, 절차, 개요, 방법을 사업과 보고 단계에 맞춰 편집하는 로컬 웹 도구입니다. 연결해주신 웹사이트의 편집 흐름을 참고해 별도로 만들었습니다.

## 실행

`dist/index.html`을 Chrome 또는 Edge에서 엽니다. 설치와 계정이 필요 없습니다. 로컬 웹 주소가 필요하면 `start_editor.ps1`을 실행하고 `http://127.0.0.1:8088/`을 엽니다. 서버 종료는 실행 창에서 Ctrl+C입니다.

## 사용

1. CDP·규제·감축사업, 착수·중간·최종, 네 도표 유형을 선택합니다.
2. **선택한 예시 불러오기**를 누릅니다. 36개 조합은 모두 가상 예시입니다.
3. 제목·핵심 메시지·기준일·사업 문맥·범위와 각 과업의 입력·활동·산출물·검토 조건을 바꿉니다. **추진절차**에서는 왼쪽의 그래프 일괄 편집란에 `단계명 | 작업 상자 1 | 작업 상자 2`를 한 단계씩 적으면 상자와 연결선이 자동 배치됩니다.
4. 오른쪽 QA/QC를 확인합니다. 오류가 있으면 SVG·PNG 내보내기가 차단됩니다. 경고는 현재 사업 자료로 확인할 항목입니다.
5. JSON을 저장해 작업 원본으로 보관하고, SVG 또는 PNG를 새 파일로 내보냅니다.

과업은 최대 8개입니다. 수행방법에서 과업 5개 이상이면 도표를 두 줄로 배치합니다. 긴 문구가 생략되면 검수 목록에 표시되므로 문구를 줄이거나 도표를 나누세요. 일정은 달력 날짜이며 내부 목표일을 법정기한으로 표시하지 않습니다. 승인과 수행 상태를 각각 관리합니다.

추진절차 그래프는 2~5단계, 단계당 1~4개 작업 상자를 지원합니다. 단계 안 상자는 위에서 아래로, 다음 단계는 왼쪽에서 오른쪽으로 자동 연결됩니다. 분기나 재검토 연결은 `1.2 > 3.1`처럼 별도 줄에 입력합니다. 없는 상자를 가리키거나 연결 형식이 틀리면 QA 오류로 내보내기를 막습니다. 이 구성은 제공하신 CDP 추진절차 PPTX의 **단계 구역·여러 작업 상자·직각 연결선**만 참고했으며 고객 로고·문구·수치는 가져오지 않았습니다.

## 원본과 데이터 보호

- 불러온 JSON 원본을 덮어쓰지 않습니다. 내보내기는 매번 새 다운로드입니다.
- 자동 저장은 해당 브라우저·기기에만 남습니다. 업무 종료 시 JSON을 따로 보관하세요.
- 외부 서버 전송이나 외부 라이브러리 호출이 없습니다. 인터넷 없이 동작합니다.
- 가상 문구·담당·날짜·증빙은 실제 자료로 바꾸어 사용하세요. 사업별 법규·질문서·방법론의 최신 판본을 대신 확인해주는 도구는 아닙니다.

## 수식

감축사업의 수식·인자는 JSON 명세로 보존됩니다. 이 편집기의 SVG·PNG 내보내기는 Office Math가 아닙니다. 실제 Word·PowerPoint 수식 편집은 함께 제작한 `20261021_innergen_report_examples_v31`의 기본 Office Math 예제와 `.claude/skills/ppt-master/scripts/office_equations.py`를 사용합니다.

## 확인한 범위

36개 사업·단계·유형 조합의 QA 오류 0, 날짜 역전·중복 ID·의존 관계 순환·승인 근거 누락·수식 기호 누락·그래프 연결 오류 등 14종 오류 검출, 입력 데이터 무변경을 확인했습니다. 브라우저에서는 그래프 자동 배치와 연결선, 오류 시 내보내기 차단, 실행 취소, JSON 저장을 확인했습니다.
