## 9. 이너캐리

- 고민→해법: 복잡한 인벤토리 구성 및 온실가스 산정 → 전문 컨설턴트가 한번에 / 수많은 사업장에 흩어져 있는 Data → 이너캐리 전용 App으로 한번에 / 공시 및 환경 규제에 맞는 Data 가공 → 이너캐리 Web으로 한번에
- 도입 방식: SaaS형(기본) 별도 설치 없이 온라인 접속. 연결회사·협력사 데이터 수집에 특화 / 사내(내부망) 설치형(옵션) 사내 ERP·MES 등과 연동하는 자체 구축형. 종속회사 데이터 통합 관리, 공시 형태 변환·API 전송 / 하이브리드형(옵션) SaaS형 + 내부망 설치형. 핵심 데이터는 사내 보관, 지사·협력사 데이터는 온라인 수집
- 5단계: 회원 가입(법인만 가입) → 사용 준비(현장 담당자 초대·전용 App 설치) → 자료 입력(매월, 약 5분 내외) → 자료 점검(본사 확인·월별 마감) → 데이터 전송(옵션: 사내 설치형·API)
- 보안 4축: 감사 로그 자동 기록(사번·타임스탬프·수정 전후 값·사유) · 역할별 권한 4단계 분리(운영관리자·사업장관리자·시설관리자·감사/모니터링) · 국내 리전 클라우드(네이버클라우드) 저장 · 개인정보보호법 준수
