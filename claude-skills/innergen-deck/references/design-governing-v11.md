# 이너젠 교육자료 거버닝 메시지 규칙 — v11

2026-10-03 사용자 요청: 단편적인 거버닝 메시지를 주어 시작 원칙과 구체적인 판단·실무 시사점으로 고도화한다. v10의 색상·음영 박스·글자 크기를 유지하며, 거버닝 문구 보존 규칙만 이번 요청 범위에서 대체한다.

## 1. 제목·거버닝·본문·최종 메시지의 역할

| 역할 | 표현할 내용 | 문체 |
|---|---|---|
| 메인 제목 / 부제목 | 번호를 포함한 목차상의 주제·세부 항목 | 명사형, 기존 제목 유지 |
| 거버닝 | 장표에서 배워야 할 핵심 원칙과 그에 따른 판단·행동 | 주어로 시작하는 완결된 합니다 체 |
| 본문 | 거버닝을 뒷받침하는 조건·사례·비교·흐름·수치 | 구조화, 명사형 종결 |
| 하단 최종 메시지 | 실제 적용 시 확인할 자료·오류·책임·다음 행동 | 구체적인 준비·확인·기억의 합니다 체 |

거버닝과 하단 메시지는 같은 문장을 반복하지 않는다. 거버닝은 판단의 방향을 제시하고 하단 메시지는 실행에 필요한 점검 사항을 짚는다.

## 2. 주어 시작 원칙

- 첫 구절에 명시적인 주어를 둔다. 책임·절차 장표는 역할 주어, 원칙·정의 장표는 기업 또는 핵심 개념을 주어로 선택한다.
- 실제로 행동하는 주체와 서술어를 맞춘다. 재무 계정·추정은 재무 담당자, 모델·시나리오는 분석 담당자, 계산·경계는 산정 담당자, 전체 검토는 검토자처럼 선택한다.
- 모든 문장을 기계적으로 “기업은”으로 시작하지 않는다. 반대로 주어를 다양하게 보이게 하려고 본문에 없는 역할이나 책임을 만들어 넣지 않는다.
- “이것은”, “이를 통해”, “중요한 것은” 등 지시어·추상적 도입은 사용하지 않는다. 독자가 제목 없이 읽어도 대상과 핵심을 파악할 수 있어야 한다.

## 3. 핵심 원칙과 판단·실무 시사점

기본 문장 구조는 **주어 + 대상·핵심 원칙 + 조건 또는 판단 기준 + 구체적인 결론·행동**이다. 모든 구성요소를 억지로 채우지 말고 해당 장표가 실제로 뒷받침하는 관계를 우선한다.

| 장표 유형 | 문장에 담을 핵심 | 필요한 구분 |
|---|---|---|
| 원칙·요구사항 | 누가 무엇을 어떤 기준으로 설명·공시하는지 | 의무·선택·허용 예외 |
| 판단·완화 | 조건에 따른 적용 대상·기간과 잔여 요구사항 | 현재/예상, 개별/결합, 중요성/유용성 |
| 비교·사례 | 차이를 만드는 조건과 자사 적용의 판단 기준 | 원문 예시/자사 사실, 사례 수/의무 수 |
| 절차·제출 | 담당자가 무엇을 연결·검토·준비하는지 | 원자료/추정/자료 공백, 작성/검토 책임 |
| 목차 | 학습의 출발점과 도달할 실무 판단 | 세부 제목의 단순 나열 금지 |

“확인해야 합니다”, “기억해야 합니다”만으로 끝나는 메시지에는 확인 대상과 기준을 붙인다. “체계적으로 관리”, “종합적으로 검토”, “연결이 중요”처럼 구체적인 행동이 없는 표현은 쓰지 않는다. 문장 길이를 늘리는 수식어·추상어·고정적인 세 항목 나열은 배제한다.

## 4. 정확성과 근거

- 거버닝의 각 주장에는 같은 장표의 본문 또는 제공 레퍼런스의 근거가 있어야 한다. 본문에 없는 수치·요건·면제·성과를 추가하지 않는다.
- 기준의 의무에는 근거가 있을 때만 “공시해야 합니다”를 사용한다. 이너젠의 자료 등록부·보완 책임자 지정 등은 교육용 실무 준비이며 새 기준 의무로 표현하지 않는다.
- 의무·선택·허용 및 적용 조건을 유지한다. 예: 역량 부족 완화는 예상 영향에 한정, Scope 3의 3년 완화와 첫해 기존 방법 허용 구분, 지역기반 필수 공시와 시장기반 추가 정보 구분.
- 중요성 판단, 정량 정보 유용성 판단, 개별 효과 분리와 결합 효과 판단을 합치지 않는다.
- 출처는 기존 문서명과 실제 PDF 페이지를 유지한다. 원문 사례 수치·단위·기간·가상 사례 표시를 보존한다.

## 5. 길이·줄바꿈·디자인

- 한 장표에 핵심 결론 하나, 원칙적으로 한 문장. 의미 관계가 명확할 때만 두 절을 연결한다.
- 글자 수만을 맞추지 않는다. 먼저 핵심 판단을 작성한 뒤 실제 설치 글꼴로 너비를 측정한다. 이 1040×720 교육자료에서는 보통 약 55~85자를 두 줄에 배치하되 공백·영문·기호의 실제 폭을 우선한다.
- 주어와 대상, 복합 명사, 조건·예외 문구를 분리하지 않는다. 첫 줄은 핵심 원칙·대상, 둘째 줄은 판단·실무 시사점에 맞춰 의미 단위로 나눈다.
- 마지막 줄이 짧은 종결부만 남는 줄바꿈은 금지한다. 두 줄 폭의 차이가 크면 의미를 보존하며 위치를 다시 선택한다.
- 기존 IBM Plex Sans KR **20pt**, 파란 볼드 **#2F62F0** 유지. 본문 **14pt**, 소제목 **16.5pt**, 제목 **24pt** 유지.
- 거버닝 음영 **#F3F6FF**, 테두리 **#DFE7FF**, 박스 x48/y98/944×60px 유지. 텍스트 x72, 두 줄 기준선 y122·150, 내부 좌우 최소24px 확보.
- 문장이 넘치면 표현·줄바꿈을 먼저 조정한다. 조건을 삭제하거나 글자를 축소해 맞추지 않는다. 박스와 본문 시작 y174의 간격을 보존한다.

## 6. 적용 예시

| 장표 | 기존 표현 | 보완 표현 |
|---|---|---|
| 현재·차기 영향 | 당기 손상 인식과 차기 장부금액 조정 위험을 구분해 기억해야 합니다. | 재무 담당자는 당기에 인식한 손상과 다음 회계연도의 조정 위험을 분리해 검토하고, 관련 계정·추정 가정·추가 정보 시점을 확인해야 합니다. |
| 회복력 입력 | 출처·범위·가정이 있어야 분석 결과를 재현할 수 있습니다. | 분석 담당자는 시나리오 원천·범위·기간과 주요 가정을 명시하고, 외부 경로와 회사 대응 가정을 구분해 결과의 전제와 산출 근거를 추적해야 합니다. |

## 7. 완료 검사

1. 모든 거버닝 문장이 명시적인 주어로 시작하는지 확인한다.
2. 대상·판단 기준·행동 또는 시사점이 본문과 연결되는지 사람이 검토한다. 문장 패턴 검사만으로 의미 품질을 통과시키지 않는다.
3. 의무와 실무 권고, 예외의 대상·기간·잔여 공시가 바뀌지 않았는지 대조한다.
4. 제목·본문·최종 메시지·출처 등 거버닝 밖의 개체와 내용이 그대로인지 비교한다.
5. 실제 글꼴 너비와 PowerPoint 렌더에서 두 줄 문장·박스 내부 여백·본문 간격·잘림을 확인한다.
6. 원본은 보존하고 새 PPTX·PDF와 문장 변경표를 제공한다.
