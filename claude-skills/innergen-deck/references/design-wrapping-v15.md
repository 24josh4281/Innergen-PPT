# 이너젠 줄바꿈·거버닝 크기 규칙 — v15

2026-10-03 사용자 피드백을 반영한다. 한 줄에 들어가는 문장의 조기 줄바꿈을 없애고, 거버닝 크기를 낮춘다. 기존 문구·조건·예외·수치·단위와 본문 가독성을 유지한다.

## 1. 적용과 우선순위

현재 사용자 요청과 프로젝트의 확정 명세를 우선한다. 신규·수정 이너젠 장표에서는 이 문서가 v5·v10·v11의 거버닝 기본 크기와 두 줄 균형 선호를 보완한다. v12~v14의 의미·근거·가시적 정보 요건과 선택된 제작 절차는 유지한다. 과거 원본의 크기·줄바꿈은 관측 자료로 보존한다.

## 2. 거버닝 크기

| 역할 | 교육형 PPT | 교육형 SVG | 발표형 PPT | 발표형 SVG |
|---|---:|---:|---:|---:|
| 거버닝 | 16.5pt | 22px | 20pt | 26.67px |
| 본문 | 14pt | 18.67px | 18pt | 24px |

위 값은 1040×720px / 780×540pt 기준의 신규 기본값이다. 사용자 확인값이 있으면 해당 값을 적용한다. 거버닝을 줄인 것을 이유로 본문·조건·예외까지 축소하지 않는다. 글꼴·색상·문장 내용은 기존 프로젝트 명세를 유지하며, 변경된 역할 크기를 프로젝트 명세와 잠금 파일에 기록한다. 모든 SVG 텍스트에는 명시적인 `font-size`를 둔다.

## 3. 실제 폭을 먼저 사용하는 줄바꿈

| 상황 | 작성·검수 기준 |
|---|---|
| 한 줄에 들어가는 문장 | 패널·셀의 실제 사용 가능한 폭에서 한 줄로 표시 |
| 폭을 넘는 문장 | 필요한 최소 줄 수로 배치하고 어절·복합 용어 경계에서 줄바꿈 |
| 첫 줄에 다음 어절이 추가로 들어가는 경우 | 조건절·복합 용어 등 함께 읽어야 하는 묶음을 제외하고 첫 줄로 이동 |
| 짧은 마지막 줄 | 종결어미만 남지 않도록 마지막 의미 묶음을 함께 이동. 두 줄 길이를 같게 만들기 위한 조기 줄바꿈은 사용하지 않음 |
| 독립된 항목·비교축·조건 | 문장 줄바꿈과 구분. 논리 항목을 한 문단으로 합쳐 여백을 채우지 않음 |
| 표 셀의 긴 설명 | 실제 셀 폭·안쪽 여백으로 판정. 불필요한 2~3줄을 줄인 뒤 셀 높이·수직 중심을 확인 |

가용 폭은 패널/셀의 오른쪽 경계에서 실제 안쪽 여백을 뺀 값이다. 다른 열·로고·아이콘 영역까지 포함한 전체 캔버스 폭을 사용하지 않는다. 설치된 실제 글꼴·굵기의 너비를 측정하고 PowerPoint·PDF에서 확인한다. 정적 추정치와 실제 글꼴 폭이 다른 경우 둘을 기록하며 출력 화면으로 확인한다.

한 문단은 하나의 편집 가능 텍스트 프레임으로 구성한다. 독립된 목록은 항목별 프레임으로 유지한다. SVG의 수동 줄바꿈이 PowerPoint에서 다시 이어지거나 좁은 프레임을 만들지 않도록 실제 내보내기 결과를 확인한다.

SVG 제작 시 실제 사용 가능한 내용 폭은 `data-pptx-text-width`에 px로 명시할 수 있다. 실제 폭에서 검토한 의미 묶음 경계는 `data-pptx-preserve-line-breaks="true"`로 내보내기에서도 유지할 수 있다. 이 옵션은 한 편집 프레임 안에 줄을 유지하며, 조기 줄바꿈을 정당화하는 용도로 사용하지 않는다. 선택한 서체는 각 `<text>`의 `font-family`에도 명시해 루트·그룹 상속 누락으로 다른 서체가 적용되지 않게 한다. 내보내기에서 폭을 넓혀 페이지나 다음 열을 침범하면 완료로 판단하지 않는다.

## 4. 여백과 수직 배치

한 줄 거버닝은 박스의 실제 글자 높이를 기준으로 수직 가운데에 둔다. 두 줄이면 두 줄 전체를 가운데에 둔다. 두 줄용 기준선을 그대로 두고 한 줄만 남겨 아래쪽 여백이 커지지 않게 한다. 박스·본문·출처 사이의 안전 간격은 유지한다.

줄 수가 줄면 뒤의 요소와 행 높이를 함께 검토한다. 내용의 묶음과 읽기 순서를 위한 여백은 유지하고, 불필요한 수동 줄바꿈으로 발생한 여백만 정리한다. 여백을 없애기 위해 문구를 삭제하거나 수치·요건을 바꾸지 않는다.

## 5. 완료 검사

| 검사 | 통과 조건 |
|---|---|
| 내용 | 수정 전후의 문구·조건·수치·단위·순서가 공백을 제외하고 일치 |
| 크기 | 실제 PPTX·PDF 거버닝 크기가 확정값과 일치, 본문 크기 유지 |
| 줄바꿈 | 한 줄 가능 문장의 불필요한 수동 줄바꿈 없음. 긴 문장은 용어 분리·짧은 종결부·잘림 없음 |
| 폭 | 실제 열·셀 경계 안에서 출력. 다음 열이나 로고 공간 침범 없음 |
| 공간 | 한 줄/두 줄의 수직 중심과 본문 간격 적절. 목록·조건 관계 유지 |
| 보존 | 원본·이전 출력본을 보존하고 새 버전과 변경·검수 기록 제공 |

이 규칙은 작성·검수 지침이다. 모든 자연어 의미 경계를 자동 판정하는 프로그램이 구현되었다는 뜻은 아니다.
