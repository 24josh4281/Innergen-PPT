## 5. GPT·Gemini 호환판의 한계

- PPTX를 직접 만들지 않는다. 목차표·문구·슬롯 명세(JSON)까지 만들고, 파일은 Claude 스킬에서 만든다.
- 자동 검사 대신 같은 코드표로 사람이 읽는 수준의 점검을 한다.
- 업로드 개수 한도는 서비스가 바꿀 수 있어 지침 1 + 지식 9개로 맞췄다(공식 한도는 작성 시점에 확인하지 못함).
