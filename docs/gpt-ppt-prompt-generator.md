# ChatGPT 채팅창용 PPT 프롬프트 생성기

## 목적

이 기능은 Innergen-PPT 앱에서 만든 Storyboard를 ChatGPT 채팅창에 그대로 붙여넣을 수 있는 고품질 프롬프트로 바꿉니다.

현재 API 직접 연결은 보류 상태입니다. 외부 API를 호출하지 않고, 사용자가 생성된 프롬프트를 복사해 ChatGPT 대화창에서 직접 실행하는 방식입니다.

## 제공 모드

- 한큐 PPT 생성: 최종 PPT 제작 지시를 바로 만들 때 사용합니다.
- Storyboard 고도화: PPT 생성 전에 제목, governing message, 장표 구조만 먼저 다듬을 때 사용합니다.
- PPT QA 리뷰: 생성된 장표 캡처나 텍스트를 다시 검토하고 개선 지시를 받을 때 사용합니다.
- PPTX 코드 구현: 개발형 GPT에게 pptxgenjs 코드와 렌더링 QA 흐름까지 맡길 때 사용합니다.

## 기본 사용 흐름

1. 원문 또는 슬라이드별 요구사항을 입력합니다.
2. `1. Storyboard 설계`를 누릅니다.
3. 장표별 제목, governing message, 추천 구조를 필요하면 수정합니다.
4. `GPT 프롬프트 생성`을 누릅니다.
5. 목적에 맞는 프롬프트 모드를 선택합니다.
6. `복사` 또는 `MD 저장`을 누릅니다.
7. ChatGPT 채팅창에 붙여넣고 실행합니다.

## 좋은 결과를 위한 입력 방식

- 장표별 핵심 메시지를 먼저 적습니다.
- 수치, 단위, 날짜, 법정 제출기한은 원문 그대로 적습니다.
- 참고자료 캡처나 근거 페이지는 본문용인지 appendix용인지 표시합니다.
- 한 장에 내용이 너무 많으면 `appendix 분리 가능`이라고 표시합니다.
- 원하는 산출물 수준을 적습니다: 제안서, 착수보고, 중간보고, 최종보고, 교육자료 등.

## 프롬프트에 포함되는 품질 규칙

- INNerGEN BI 색상 유지: Navy, Sky Blue, White, Light Gray
- 한글 안전 폰트 사용: 맑은 고딕 우선
- 본문 최소 11pt 이상, 가능하면 14pt 이상
- 제목과 governing message 분리
- 한 슬라이드 최대 5개 bullet
- 박스 안 긴 문장은 bullet 또는 표로 전환
- 한글 짧은 단어와 라벨은 한 줄 유지
- 오버플로우, 겹침, 글자 단위 줄바꿈 금지
- 내부 작업 메모는 본문 장표에서 제거

## API 보류 상태

API 연결 코드는 후속 확장을 위해 남겨둘 수 있지만, 현재 화면에서는 `GPT 실행` 버튼을 제거했습니다. 따라서 앱에서 외부 API로 자료가 자동 전송되지 않습니다.

고객사 기밀자료, 미공개 배출량, 견적, 개인정보가 포함된 경우에는 ChatGPT 채팅창에 붙여넣기 전에도 내부 보안 기준을 먼저 확인해야 합니다.
