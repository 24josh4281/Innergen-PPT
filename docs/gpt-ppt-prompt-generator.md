# ChatGPT 채팅창용 PPT 프롬프트 생성기

## 목적

이 기능은 Innergen-PPT 앱에서 만든 Storyboard를 ChatGPT 채팅창에 그대로 붙여넣을 수 있는 고품질 프롬프트로 바꿉니다.

현재 API 직접 연결은 보류 상태입니다. 외부 API를 호출하지 않고, 사용자가 생성된 프롬프트를 복사해 ChatGPT 대화창에서 직접 실행하는 방식입니다.

## 제공 모드

- 한큐 PPT 생성: 최종 PPT 제작 지시를 바로 만들 때 사용합니다.
- Storyboard 고도화: PPT 생성 전에 제목, governing message, 장표 구조만 먼저 다듬을 때 사용합니다.
- PPT QA 리뷰: 생성된 장표 캡처나 텍스트를 다시 검토하고 개선 지시를 받을 때 사용합니다.
- PPTX 코드 구현: 개발형 GPT에게 pptxgenjs 코드와 렌더링 QA 흐름까지 맡길 때 사용합니다.

## 기본 사용 흐름

1. 원문 또는 슬라이드별 요구사항을 입력합니다.
2. `1. Storyboard 설계`를 누릅니다.
3. 장표별 제목, governing message, 추천 구조를 필요하면 수정합니다.
4. `GPT 프롬프트 생성`을 누릅니다.
5. 목적에 맞는 프롬프트 모드를 선택합니다.
6. `복사` 또는 `MD 저장`을 누릅니다.
7. ChatGPT 채팅창에 붙여넣고 실행합니다.

## 좋은 결과를 위한 입력 방식

- 장표별 핵심 메시지를 먼저 적습니다.
- 수치, 단위, 날짜, 법정 제출기한은 원문 그대로 적습니다.
- 참고자료 캡처나 근거 페이지는 본문용인지 appendix용인지 표시합니다.
- 한 장에 내용이 너무 많으면 `appendix 분리 가능`이라고 표시합니다.
- 원하는 산출물 수준을 적습니다: 제안서, 착수보고, 중간보고, 최종보고, 교육자료 등.

## 좋은 PPT로 수렴시키는 추가 장치

프롬프트 생성기는 단순히 내용을 예쁘게 요약하라고 지시하지 않습니다. 사용자가 준 입력을 먼저 진단하고, 컨설팅 장표로 바꾸는 절차를 강제합니다.

- 입력 진단: 자료를 `Complete`, `Partial`, `Risky`로 나누고 부족한 정보가 있으면 가정표와 확인 필요 항목을 분리합니다.
- 슬라이드 역할 지정: 각 장표를 배경 설명, 문제 진단, 비교, 방법론, 일정, 산출물, 의사결정, Appendix 중 하나로 분류합니다.
- Governing message 강제: 모든 장표는 제목과 별도로 한 줄 주장 또는 판단 메시지를 갖습니다.
- 구조 선택 강제: 카드형 반복을 기본값으로 두지 않고, 매트릭스, 타임라인, 비교표, 워크스트림, 스윔레인, 계층도 등에서 내용에 맞는 구조를 고릅니다.
- 산출 계약: 각 슬라이드마다 Role, Evidence, Recommended layout, Body blocks, Visual treatment, QA risk를 채우게 합니다.
- 자기검수: 응답 전 오버플로우, 한글 단어 쪼개짐, bullet 과다, 구조 반복, 정보 보존 리스크를 다시 점검하게 합니다.

## 입력이 부족할 때 처리 방식

사용자가 간단한 프롬프트만 주는 경우에도 바로 멈추지 않도록 설계했습니다.

- 치명적 누락이 아니면 합리적 가정을 명시하고 초안을 진행합니다.
- 숫자, 규제, 제출기한, 책임 범위처럼 틀리면 위험한 정보가 부족하면 최대 3개 질문을 먼저 제시합니다.
- 질문이 필요한 경우에도 임시 장표 방향과 확인 후 보정 포인트를 함께 제시합니다.
- 원문 사실, 가정, 디자인 판단을 섞지 않고 분리해 추적성을 유지합니다.

## 프롬프트에 포함되는 품질 규칙

- INNerGEN BI 색상 유지: Navy, Sky Blue, White, Light Gray
- 한글 안전 폰트 사용: 맑은 고딕 우선
- 본문 최소 11pt 이상, 가능하면 14pt 이상
- 제목과 governing message 분리
- 한 슬라이드 최대 5개 bullet
- 박스 안 긴 문장은 bullet 또는 표로 전환
- 한글 짧은 단어와 라벨은 한 줄 유지
- 오버플로우, 겹침, 글자 단위 줄바꿈 금지
- 내부 작업 메모는 본문 장표에서 제거
- 동일한 카드형 레이아웃이 반복되면 더 적합한 컨설팅 구조로 교체
- 최종 답변에 확인 필요 정보와 수정 필요 슬라이드 표시

## PPTX 생성 후 반복 QA

앱에서 `PPTX 생성`을 누르면 생성본을 한 번만 검사하지 않고 최대 3회까지 반복 QA합니다.

1. 1차 QA: 원본 생성본의 최소 폰트, 오버플로우 위험, 겹침 위험, 한글 단어 깨짐 위험을 검사합니다.
2. 2차 QA: 위험이 있으면 긴 문장을 줄이고, 섹션 수를 줄이며, 라벨을 한 줄로 유지하도록 자동 보정한 뒤 다시 생성합니다.
3. 3차 QA: 여전히 위험이 있으면 더 보수적으로 본문을 압축하고 다시 검사합니다.

다운로드 영역에는 각 QA 차수별 점수와 위험 건수가 표시됩니다. 최종 파일은 가장 좋은 QA 점수를 받은 생성본을 기준으로 제공합니다.

## API 보류 상태

API 연결 코드는 후속 확장을 위해 남겨둘 수 있지만, 현재 화면에서는 `GPT 실행` 버튼을 제거했습니다. 따라서 앱에서 외부 API로 자료가 자동 전송되지 않습니다.

고객사 기밀자료, 미공개 배출량, 견적, 개인정보가 포함된 경우에는 ChatGPT 채팅창에 붙여넣기 전에도 내부 보안 기준을 먼저 확인해야 합니다.
