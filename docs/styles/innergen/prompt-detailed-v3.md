# 이너젠 상세 교육자료 요청 프롬프트

```text
제공 자료로 이너젠 스타일의 상세 교육 PPT를 만들어줘.
docs/styles/innergen/design.md, design.json, design-v2.md, design-v2.json과
design-detailed-v3.md, design-detailed-v3.json을 읽고 적용해.

본문은 실제 PowerPoint 14pt로 작성하고 제목·소제목은 계층을 유지해.
장표만 읽어도 실제 학습과 실무 확인이 가능하도록 구체적 요구사항·조건·예외·기간·대상,
예외 뒤에도 필요한 공시, 확인할 자료·판단 근거를 장표 안에 담아.
핵심 설명을 별도 원고로만 보내지 말고 도식과 설명을 결합해.
교육용 사례·실무 해설은 기준서의 요구사항과 구분해.
관계에 맞는 포함·분기·비교·인과·환류·시간축·역할 도식을 사용해.

출처는 문서명과 제공 PDF의 파일 페이지로만 표시해.
문단 번호와 원고 번호는 장표 출처에서 제외해.
원본과 이전 버전을 보존하고 새 버전으로 저장해.
실제 14pt와 텍스트·도형 편집성, PDF 문장 누락·잘림·겹침·출처·주제 대응을 검사해.
PowerPoint 전체를 렌더하고 밀도 높은 대표 장표를 검토한 뒤 PPTX와 PDF를 함께 제공해.
```
