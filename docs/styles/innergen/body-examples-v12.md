# 이너젠 본문 가공·구조 판별 예시 — v12

모든 예시는 규칙 확인용 가상 자료다. 실제 기업·기준서·배출량·법적 의무의 근거로 재사용하지 않는다. 아래 본문은 의미 기획 예시이며 실제 PowerPoint의 글꼴 폭·넘침·편집성은 검사하지 않았다.

## 1. 한 문장의 현황·영향·계획을 진단표로 분해

**가상 원문 S01**: “사업장별 입력 양식이 달라 취합 후 형식을 다시 정리하고 있으며, 공통 입력 양식을 도입할 계획이다.”

| ID | 분해한 진술 | 상태·근거 |
|---|---|---|
| C01 | 사업장별 입력 양식이 다름 | 원문 사실 진술, S01 |
| C02 | 입력 양식 차이로 취합 후 형식 재정리 발생 | 원문이 설명한 영향, S01 |
| C03 | 공통 입력 양식 도입 계획 | 계획, S01 |

**질문·선택**: “왜 취합 후 추가 작업이 발생하고 어떤 대응을 계획하는가?” → C01 진단표. 원문에 문제·원인·영향·계획의 연결이 있다.

| 문제 | 원인 | 영향 | 대응 |
|---|---|---|---|
| 취합 후 추가 작업 | 사업장별 입력 양식 상이 | 취합 후 형식 재정리 | 공통 입력 양식 도입(계획) |

| 장표 요소 | 문구·근거 |
|---|---|
| 제목 | `자료 취합 / 입력 양식과 대응 계획` |
| 거버닝 | `사업장별 입력 양식 차이로 취합 후 재정리가 발생하며, 공통 양식 도입이 계획돼 있습니다.` — C01~C03 |
| 하단 | `검토자는 계획의 구체화를 위해 공통 양식의 적용 범위와 도입 시점을 추가로 확인할 수 있습니다.` — C03 기반 실무 제안 |
| 미확인 | 담당자·기한·절감공수·효익 수치 없음 |

`양식 통일로 생산성20% 향상`, `ESG팀이 연말까지 도입`, `현재 공통 양식 운영`은 생성하지 않는다. 하단의 확인 행동은 원문 계획과 구분한 실무 제안이다. 같은 원문에서 경영진이 “어떤 계획인가?”만 묻는다면 단일 계획·현황표로 표현할 수 있으나 원인·영향은 상세 근거와 연결한다.

## 2. 자료 미제시와 미운영 구분

**가상 내부 기준 S02**: “입력값을 변경한 경우 승인 기록을 보관한다.”

**가상 검토 메모 S03**: “현재 제공된 자료에는 승인 기록이 포함돼 있지 않다. 실제 승인 절차의 운영 여부는 확인하지 않았다.”

| ID | 진술 | 상태 |
|---|---|---|
| C04 | 입력값 변경 시 승인 기록 보관 | 가상 내부 기준, S02. 법령 의무가 아님 |
| C05 | 제공 자료에 승인 기록 미포함 | 관찰, S03 |
| C06 | 승인 절차 운영 여부 미확인 | 미확인, S03 |

**질문·선택**: “현재 증빙으로 내부 기준 준수 여부를 판단할 수 있는가?” → C02 기준·증빙·판단·보완표.

| 내부 요구사항 | 제공 증빙 | 판단·확인 격차 | 보완 |
|---|---|---|---|
| 입력값 변경 시 승인 기록 보관 | 현재 자료에서 승인 기록 미확인 | 실제 운영·준수 여부 판단 보류 | 관련 승인 기록 및 운영 여부 확인(실무 제안) |

거버닝: `검토자는 승인 기록이 제공되지 않은 상태를 절차 미운영으로 단정할 수 없으며, 실제 운영 여부를 추가로 확인할 필요가 있습니다.`

하단: `검토자는 변경·승인 기록과 절차 운영 근거를 요청해 판단을 보완할 수 있습니다.` — 실무 제안.

근거: 요구=C04, 증빙=C05, 판단=C04+C05+C06, 보완=C04~C06 기반 제안. `규정 위반`, `승인 통제 미운영`, `0건`은 결론으로 만들지 않는다.

## 3. AND 조건·부정 경로·잔여 사항 보존

**가상 내부 절차 S04**: “대상이 사전 등록돼 있고 담당자 확인이 완료된 경우 간소 검토를 적용한다. 두 조건 중 하나라도 충족하지 않으면 일반 검토를 적용한다. 모든 경우 최종 승인 기록을 보관한다.”

| ID | 진술 |
|---|---|
| C07 | 사전 등록 AND 담당자 확인 완료 시 간소 검토 적용 |
| C08 | 하나라도 미충족 시 일반 검토 적용 |
| C09 | 간소·일반 검토 모두 최종 승인 기록 보관 |

**질문·선택**: “어떤 조건에서 간소 검토를 적용하며 무엇은 계속 필요한가?” → D04 조건 분기. 가상의 내부 절차이며 공시 면제 사례가 아니다.

```text
사전 등록 및 담당자 확인이 모두 완료됐는가?
  ├─ 예: 간소 검토 적용
  └─ 아니오: 일반 검토 적용
공통 잔여 사항: 최종 승인 기록 보관
```

| 연결·구획 | 근거 |
|---|---|
| 질문→예 경로 | C07, AND 보존 |
| 질문→아니오 경로 | C08, 하나라도 미충족 |
| 공통 잔여 사항 | C09, 두 결과에 적용 |

거버닝: `간소 검토는 사전 등록과 담당자 확인을 모두 충족할 때 적용하며, 최종 승인 기록은 모든 경우에 보관합니다.`

하단: `검토자는 두 조건의 충족 여부와 최종 승인 기록을 함께 확인할 수 있습니다.` — 실무 제안.

`사전 등록 또는 담당자 확인`, `간소 검토는 승인 면제`로 바꾸면 실패다. “하나라도 미충족”을 모든 조건 미충족으로 바꾸지 않는다. 미확인 상태의 조건 충족 여부도 추정하지 않는다.

## 4. 번호 목록·협업·동시 발생에서 관계를 만들지 않기

| 가상 원문 | 맞는 표현 | 배제할 표현·이유 |
|---|---|---|
| S05: `세 가지 과제는 기준 마련, 교육, 검증이다.` | A01 병렬 과제·상세표, 각 항목의 설명이 없으면 명칭만 보존 | D01의 기준→교육→검증: 선후관계 없음 |
| S06: `기준 마련 후 교육을 실시하고 교육 종료 후 검증한다.` | D01 단계별 수행 또는 설명이 긴 D02 | 독립 카드만 사용해 실제 순서를 삭제 |
| S07: `이사회·경영진·ESG팀이 협력한다.` | 역할·협력 주체 목록. 구체 역할도 원문 범위 내 표시 | E02 보고체계 또는 E06 RACI: 권한·배정 없음 |
| S08: `ESG팀은 검토 결과를 경영진에게 보고한다.` | 보고선 ESG팀→경영진, 라벨 `검토 결과 보고` | 경영진→ESG팀 승인선: 승인 권한·행위 없음 |
| S09: `양식 변경과 검토시간 단축이 관찰됐다.` | 병렬 관찰표 | F01 인과: 함께 관찰됐다는 이유로 원인 판정 불가 |
| S10: `양식 변경으로 검토시간이 단축됐다고 보고서는 설명한다.` | 인과 설명 + `원문 주장` 표시 | 독립 검증된 인과·정량 효익으로 강화 |

모든 관계는 해당 S번호 문장을 근거로 판단한다. 원문에 없는 하위 역할·승인·수치·순서는 추가하지 않는다. 내용이 한 문장으로 충분하면 한 문장이나 단순 표를 사용한다.

## 5. 정성 기후영향을 금액으로 만들지 않기

**가상 원문 S11**: “탄소가격이 상승하면 배출권 순구매량이 있는 사업장의 배출권 구매비용이 증가할 수 있다. 비용 금액과 순구매량은 제시하지 않았다.”

| ID | 진술·상태 |
|---|---|
| C10 | 탄소가격 상승 조건 | 조건부 입력, S11 |
| C11 | 배출권 순구매량이 있는 사업장 | 영향의 적용범위, S11 |
| C12 | 배출권 구매비용 증가 가능 | 원문의 정성 영향 주장, S11 |
| C13 | 금액·순구매량 미제시 | 자료 한계, S11 |

**질문·선택**: “탄소가격 변화가 어떤 조건에서 어떤 비용에 영향을 줄 수 있는가?” → F02 정성 영향 경로 또는 짧은 조건·영향표. 재무 계정·회계 인식은 미확인으로 둔다.

| 외부동인 | 적용 조건·사업경로 | 결과·한계 |
|---|---|---|
| 탄소가격 상승 | 배출권 순구매량이 있는 사업장 | 배출권 구매비용 증가 가능 / 금액 미제시 |

거버닝: `탄소가격 상승은 배출권 순구매량이 있는 사업장의 구매비용을 높일 수 있으며, 금액 영향은 제공 자료로 확정할 수 없습니다.`

하단: `분석 담당자는 정량화에 앞서 순구매량과 가격 가정을 확보하는 방안을 검토할 수 있습니다.` — 실무 제안.

차트·금액·현금흐름·EBITDA·발생확률·투자지출·회사 전체 영향은 추가하지 않는다. 화살표를 사용할 경우 연결 근거=C10+C11+C12, 상태=`증가 가능`이다. 확인된 구매비용을 임의로 특정 회계계정과 동일시하지 않는다.

## 6. 숫자가 있어도 차트가 안 되는 경우

아래 값은 검토용 가상 값이다. 실제 배출량을 수정하거나 합산한 결과가 아니다.

| 입력 | 선택 | 이유·보존할 정보 |
|---|---|---|
| S12: `A의 Scope 1은 2025년 100 tCO₂e, B의 Scope 2는 2024년 120 tCO₂e` | 범위·기간을 표시한 자료표 | 서로 다른 Scope·연도. 동일 지표 순위 막대 배제 |
| S13: `동일 지표·방법·2025년 범위의 A 100, B 120 tCO₂e` | H01 규모 막대 후보 | 원문이 동일 조건을 명시. 축·단위·값·영점·정밀도 검토 필요 |
| S14: `준비 단계는 2025년, 실행 단계는 2026년` | 날짜가 연결된 일정표 | 연도 숫자를 막대 높이로 사용하지 않음 |
| S15: `항목의 중요도가 높고 시급하다` | 판정 근거 확인표 | 두 축의 척도·항목별 값 없음. 2×2 좌표 생성 불가 |
| S16: `시나리오 A는 비용 증가 가능, B는 영향 미확인` | B05 정성 가정·영향 비교표 | 임의 차트 높이·확률 금지 |
| S17: `실적 100과 목표 80, 단위·기간·경계 없음` | 실적/목표 상태와 미확인을 표시한 표 | 같은 기준의 격차 계산·목표 달성률 확정 보류 |

H03 구성비에는 공통 분모·배타적 항목, H04 워터폴에는 가산관계, H06 산점도에는 같은 대상의 값 쌍, H07 민감도에는 기준모형과 변수별 재계산 근거가 필요하다. 자료가 없으면 보기 좋은 위치·높이로 대신하지 않는다. 예시에서는 실제 차트를 렌더하거나 계산하지 않았다.

## 7. 충돌·분할·제안의 경계

| 가상 상황 | 올바른 처리 | 잘못된 처리 |
|---|---|---|
| S18: 상단 목표연도2027, 본문 동일 목표연도2028 | 두 값을 원문 위치와 보존, `목표연도 충돌·확인 필요` 표시 | 최신처럼 보이는2028만 선택 |
| S19: 긴 비교표에 조건·예외가 포함 | 같은 헤더·범위·단위 반복, 행 또는 대상 묶음으로 분할, 이동 ID 기록 | 예외 열 삭제 또는 출처 영역 침범 |
| S20: 5단계마다 긴 활동·산출물 있음 | D02 세로형 또는 개요+단계별 상세 | 작은 글씨로 5개 동일 상자에 압축 |
| S21: 조치 계획은 있으나 담당·기한 없음 | `담당·기한 확인 필요` 표시 또는 열 생략 | 부서·연도 자동 배정 |
| S22: 승인 이력 관리장치를 편집자가 제안 | `승인 이력 기록(실무 제안)` 및 문제 근거 연결 | 원문 기준의 필수 요구사항으로 표기 |

중요한 예외·조건·반대 근거는 본문에 남긴다. 보조 상세가 다음 장·부록으로 이동하면 `Cxx→상세Pxx`처럼 목적지를 기록한다. 장수 보존 요청과 분할이 충돌하면 변경이 필요한 부분을 제시하고 조정한다.

## 8. 실무 검토 질문

| 확인 질문 | 합격 조건 |
|---|---|
| 질문·본문 대응 | 한 장표의 주구조가 독자의 핵심 질문에 답함 |
| 같은 수준·행키 | 모든 형제 항목·표 행이 동일 분류·반복 단위 |
| 관계 근거 | 선·축·점수가 원문 또는 표시된 분석·가정으로 설명됨 |
| 강도 보존 | 계획≠실적, 가능≠확정, 미제시≠없음, 원문 주장≠독립 검증 |
| 조건·범위 | AND/OR·부정·예외·기간·경계·단위가 원문과 일치 |
| 판단·실행 | 거버닝은 본문 근거, 하단 제안은 제안으로 구분 |
| 검사 범위 | 의미 검토와 실제 PPTX 렌더 검사를 구분해 보고 |

이 예시는 판단 기준을 설명한다. 자동 구조 선택의 일반 정확도나 모든 PPTX의 가독성을 측정한 시험 결과가 아니다.
