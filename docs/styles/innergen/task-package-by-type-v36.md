# 사업 유형별 제안·착수 핵심 장표 4종 라이브러리 v36

2026-11-08 사용자 요청("과업배경, 추진절차, 상세 일정, 과업 상세 등 4개 모두 정리")을
반영한다. 제안서·착수보고의 네 장표를 사업 유형별로 어떤 이너젠 기존 디자인으로 만들지,
일정과 범위에 무엇을 넣을지 정한다. 과업 배경·필요성 문구는
[task-background-v35.md](task-background-v35.md)가 담당하고, 이 문서는 네 장표의 연결과
디자인·일정·범위를 담당한다.

- **레퍼런스는 구조만 쓴다.** 고객명·로고·문장·수치·일정을 새 사업 사실로 옮기지 않는다.
- **출처는 공개자료만 쓴다.** 이너젠 내부자료와 고객 CDP 응답은 출처로 쓰지 않는다.
- **기간은 표준 예시다.** 아래 개월 수는 [착수일]과 고객 일정으로 조정한다. 법정 기한과
  평가 창구는 해당 연도 공지로 다시 확인한다.
- 착수·중간·최종 단계 표현은 [report-diagrams-v30.md](report-diagrams-v30.md)를 따른다.

## 1. 4종의 연결 규칙

| 장표 | 답하는 질문 | 필수 내용 |
|---|---|---|
| 과업 배경 | 왜 지금 필요한가 | 외부 요구, 고객 상황, 대응 방향 |
| 세부 추진절차 | 어떤 순서로 하는가 | 단계 구역, 단계별 작업 상자, 선후 연결, 수행 주체 |
| 상세 일정 | 언제 하는가 | 과업군·세부 과업, 기간, 보고 시점, 자료 제출·검토 |
| 과업 상세 | 무엇까지 하는가 | 대상, 포함, 범위 밖, 산출물, 인수 기준 |

1. 먼저 과업을 분해해 ID를 붙이고 활동·입력·담당·기간·산출물·검토 조건을 대응시킨다.
2. 같은 과업은 추진절차의 단계, 일정의 업무 범위, 과업 상세의 항목에서 이름과 순서를 맞춘다.
3. 배경에서 제기한 요구는 과업 상세의 포함 항목이나 산출물 중 하나로 답한다.
4. 정보가 없으면 만들어 채우지 않고 `[ ]`, 미확정, 자료 요청으로 남긴다.

- 표의 빈 칸에도 작은 글자 크기를 지정한다. 지정하지 않으면 기본 18pt 때문에 행이 늘어나
  표가 출처 줄을 덮는다.
- 간트 세부 과업 글자는 14.67px, 행은 14개 안팎으로 둔다. 많으면 글자를 줄이지 않고 쪽을 나눈다.
- 과업군 색은 구분용이다. 상태 의미는 문자와 범례로 함께 쓴다.
