# 이너젠 교육자료의 구획·간격·강조·학습 메시지 v7

2026-10-02 최신 사용자 피드백을 반영한다. v4/v5의 정보 위계·문체·번호·목차와 v6의 본문 12pt를 유지하며, 이번 규칙으로 배치와 교육 메시지를 보완한다.

- **의미 구획**: 비교·절차·증빙·사례의 제목과 설명을 하나의 배경/테두리 구획 안에 배치한다. 흰 바탕에 제목·설명만 흩어져 경계를 알 수 없는 구획을 만들지 않는다. 관계를 보여주는 화살표·환류·계층은 유지한다.
- **간격**: 1040×720px 화면에서 구획 간 16px, 내부 좌우 24px를 기본으로 한다. 제목과 첫 본문의 기준선 간격은 30~34px, 본문 줄 간격은 24~26px로 맞춘다. 같은 위계의 박스·제목·텍스트 시작 위치를 정렬한다. 연결선에는 8px 단위 공간을 허용한다.
- **여백**: 글자 축소 후 이전 좌표를 무조건 유지하지 않는다. 실제 내용 높이에 맞게 배경과 연결선을 함께 재배치한다. 과도한 내부 여백·끊어진 설명·최종 박스와의 불규칙한 간격을 수정한다. 정렬을 위해 내용을 삭제하거나 출처 영역을 침범하지 않는다.
- **강조**: 본문 중요어는 볼드 700, 핵심 적용 조건·판단 기준은 파란 볼드 #13387B로 선택 강조한다. 놓치기 쉬운 예외·금지·기간 제한에는 빨간 밑줄 #FF0000을 사용한다. 한 구획에서 핵심어 1~2개를 중심으로 선택하고 모든 문장을 강조하지 않는다. 진한 배경에서는 흰 볼드를 사용한다.
- **거버닝**: 장표를 읽고 기억해야 할 핵심 조건·구분을 구체적으로 지목하며 ‘기억해야 합니다·준비해야 합니다·대비해야 합니다’ 문체를 사용한다. 추상적인 ‘연결합니다·관리합니다’만으로 끝내지 않는다.
- **최종 메시지**: 한 문장(필요 시 두 줄)에 준비할 증빙·판단 근거·검토 대상과 오해하기 쉬운 조건을 담는다. 거버닝의 단순 반복을 피한다. 교육용 실무 권고를 기준서의 추가 의무처럼 표현하지 않는다.
- **보존·검사**: 본문 요구사항·예외·수치·단위·출처, 제목 번호·목차 페이지와 본문 12pt를 보존한다. 실제 PowerPoint 출력에서 배경 경계·간격·글자 누락·강조 색/볼드·빨간 밑줄·최종 박스 두 줄을 검사한다.

새 글꼴 크기 또는 다른 화면은 현재 사용자 지정과 새 프로젝트 명세로 결정한다. 수치는 이번 화면의 기준이며 다른 비율에 단순 확대 적용하지 않는다.
