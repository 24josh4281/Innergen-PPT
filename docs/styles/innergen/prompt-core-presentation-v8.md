# 이너젠 핵심 발표 자료 제작 프롬프트 v8

제공한 PDF·PPT를 근거로 이너젠용 편집 가능한 핵심 발표 PPTX와 PDF를 제작한다. `design-core-presentation-v8.md`와 동명의 JSON을 읽고 해당 프로젝트의 디자인 명세를 먼저 작성한다. 같은 자료를 재구성할 때 원본은 보존한다.

중복과 단편적인 나열은 통합하되 조건·예외·판단 근거·실제 학습에 필요한 사례와 단위를 유지한다. 장수는 주제에 맞게 결정한다. 본문은 12pt, 소제목 14.5pt, 거버닝 20pt, 상단 제목 24pt로 유지한다.

상단은 목차에 대응하는 ‘번호 메인 주제 / 번호 부제목’으로 작성한다. 그 아래에는 기억해야 할 핵심 구분이나 대비할 조건을 구체적으로 지목하는 합니다 체 거버닝을 배치한다. 두 번째 장표에는 실제 페이지가 있는 목차를 작성한다.

본문은 위험→사업→재무의 경로, 포함 관계, 조건 분기, 같은 축의 비교 등 의미가 보이는 도식·표로 구성하고 명사형으로 마무리한다. 제목과 설명을 배경·테두리 구획 안에 함께 묶는다. 구획 간격 16px, 내부 좌우 24px, 본문 줄 간격 24~26px를 기본으로 정렬한다. 표는 가로·세로 가운데 정렬한다.

중요어는 볼드, 핵심 적용 조건은 #13387B 파란 볼드, 특히 놓치기 쉬운 금지·예외·기간 제한은 #FF0000 빨간 밑줄로 선택 강조한다. 최종 박스에는 준비할 증빙·판단 근거·검토사항을 짚는 한 문장(최대 두 줄)을 작성한다. 거버닝을 그대로 반복하지 않는다.

줄바꿈은 단어 단위로 하고 실제 폭·높이와 관계 도형을 점검한다. 짧은 마지막 줄, 과도한 여백, 개체 침범은 배경·좌표와 함께 수정한다. 글자 축소로 해결하지 않는다. 출처는 문서명과 PDF 실제 페이지로 작성한다.

규정의 필수·선택·조건부 요구와 내부 실무 제안을 구분한다. 원문 수치·분모·기간·예외 조건을 임의로 변경하지 않는다. 원문이 불일치하면 차이를 표시하고, 기준서 대조로 보완한 내용은 근거를 기록한다. 가상 사례·옛 계수·시나리오 버전을 실제 회사의 현행 실적이나 목표로 전재하지 않는다.

실제 PowerPoint에서 전체 PPTX를 PDF·PNG로 출력해 목차 대응, 모든 글자, 본문 12pt, 강조, 간격, 소계·합계와 계산을 검사한다. 검증된 5세트의 제작 명세를 재사용할 때도 새 내용에 대한 검토를 생략하지 않는다.
