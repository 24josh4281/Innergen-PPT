## 간격·표·도식·그림

- 열 사이12pt, 블록 사이12pt. 2열 너비=(본문 너비−12)÷2, 3열=(본문 너비−24)÷3.
- 패널 안쪽 좌우18pt·상하6pt. 표 셀 좌우9pt·상하6pt. 표 셀은 가로·세로 가운데 정렬.
- 행 높이는 `ceil(줄 수 × 글자 pt × 1.2 + 위·아래 여백)` 이상. 14pt 표는 한 줄29pt 이상, 두 줄46pt 이상.
- 기본 테두리0.75pt, 연결선1.25pt, 모서리 반경0pt. 도식 아이콘24pt 기준, 라벨 간격6pt.
- 같은 역할의 x/y/너비 차이는0.75pt 이내. 의도된 비대칭·들여쓰기는 명세에 이유를 남긴다.
- 자동 글자 축소는 사용하지 않는다. 문장을 정리하거나 열·행을 나누고, 필요하면 장표를 나눈다. 규제 조건·예외·값·단위는 삭제하지 않는다.
- 제목·표·출처 영역 침범과 화면 밖 글씨는 오류 후보로 검사한다. 사진의 의도된 배경 확장은 텍스트 잘림과 구분한다.
- 그림은 원래 비율을 유지한다. 최종 배치 기준150ppi 이상을 권장하며, 캡처의 핵심 문구는 본문에도 풀어 쓴다.
- 도식은 실제 순서·소속·관계가 있을 때만 연결한다. 병렬 항목을 임의의 인과관계로 바꾸지 않는다.

## 자료·이미지 수집

도식 중심 / 자료·이미지 찾기 / 도식+자료 / 설명용 생성 이미지로 구분한다. 검색과 생성은 선택된 기존 실행 경로의 이미지 단계에서 수행한다. 선택 화면 자체가 이미지를 내려받았다고 표시하지 않는다. 출처 URL·기관·확인일·사용 조건·캡션·대체 설명·삽입 위치·확인 상태를 기록하고, 취득 실패는 Needs-Manual로 남긴다. 설명용 생성 이미지를 실제 제품 화면·산정 근거로 쓰지 않는다. 이너캐리 홈페이지는 아직 시각 확인하지 못했다.

## 검사와 재사용

통합 JSON 하나에서 선택 미리보기·새 프로젝트 명세·수치 검사 기준을 읽는다. 원본 설정 검사, 로컬 폰트 실측, PowerPoint 렌더링, 신규 산출물 검증을 구분한다. 각각 통과한 검사만 완료로 표시한다.

- 원본: SHA-256 변경0건, 요청된 모든 파일 포함 확인.
- 규칙: pt/px 환산, 영역 경계, 색상·글자 크기, 모드별 줄높이 점검.
- 화면: 세 디자인·모든 사업/보고 조합·구조 변경·상세 설정·선택값 저장/복원 확인.
- 산출물: 실제 PPT의 사용 폰트·크기·여백·넘침·출처를 검사하고 렌더를 눈으로 확인. 원본 관측값을 신규 장표 검증 통과로 오인하지 않는다.
