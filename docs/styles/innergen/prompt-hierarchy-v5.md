# 이너젠 교육자료 작성 프롬프트 v5

저장된 이너젠 기본 디자인과 `design-hierarchy-v4.md/json`을 적용하고, 번호·목차·거버닝 간격은 최신 `design-hierarchy-v5.md/json`을 우선 적용하세요.

1. 표지 다음 2페이지에 목차를 만드세요. 본문 순서와 의미를 기준으로 대주제 번호와 세부 항목 번호를 부여하세요. 제목 형식은 `3. 필수 항목 / 3-1. 거버넌스`입니다. 표지·목차는 장 번호에서 제외하고, 목차의 오른쪽에는 실제 장표 페이지를 표시하세요.
2. 본문 모든 장표의 상단 제목/부제목에 같은 번호를 반영하세요. 목차 항목·본문 제목·페이지를 일대일로 대조하고 삽입 이후 푸터와 전체 페이지 수를 갱신하세요.
3. 상세 교육자료의 거버닝은 20pt, 본문은 14pt로 사용하세요. 거버닝은 가장 중요한 요약을 `~입니다/합니다`의 완결 문장으로 작성하세요. 헤더 아래와 첫 본문 위의 실제 글자 여백을 맞춰 수직 중심에 배치하세요. 두 줄이면 문단 전체 높이를 계산하고 본문을 재배치하세요.
4. 구조화 본문은 명사형, 내용이 많은 장표의 최종 박스는 형식체 한 문장 1–2줄로 마무리하세요. 조건·예외·기간·대상·단위·근거를 보존하세요. 표 가로·세로 가운데 정렬, 단어 경계 줄바꿈, 짧은 문장 꼬리와 구획 침범 방지 규칙을 유지하세요.
5. 원본을 보존하고 새 버전으로 제작하세요. 실제 PowerPoint PDF/이미지로 목차 번호·페이지, 거버닝 간격, 글자 크기와 침범 여부를 확인한 뒤 PPT와 PDF를 전달하세요.
