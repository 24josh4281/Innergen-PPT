# 이너젠 상세 교육자료 프롬프트 v6

제공한 자료로 이너젠 스타일의 편집 가능한 상세 교육 PPT를 작성한다.
design-hierarchy-v4/v5의 정보 위계·문체·구조·목차·간격 규칙을 적용하며,
글자 크기는 최신 design-hierarchy-v6.md/json을 우선한다.

본문·표·도식·최종 메시지는 12pt, 본문 소제목과 목차 대주제는 14.5pt,
목차 장별 페이지 범위는 10pt로 작성한다. 상단 제목은 24pt, 거버닝은 20pt,
출처는 10pt로 유지한다. 표지 제목·상단 표제와 푸터·페이지 표시도 유지한다.
상단은 번호가 있는 메인 제목/부제목, 아래 거버닝은 ~입니다/합니다 체,
구조화 본문은 명사형, 마지막 박스 문장은 거버닝과 같은 문체를 적용한다.
목차는 2페이지에 작성하고 본문 번호·문구·실제 페이지를 대조한다.
단어 경계 줄바꿈, 표의 가로·세로 가운데 정렬, 실제 출력의 여백·침범을 확인한다.

기존 장표의 크기만 수정하는 요청에는 내용·수치·조건·좌표·도형·줄바꿈을 보존한다.
원본은 보존하고 새 버전의 PPT·PDF를 생성하며 실제 글자 크기와 내용 누락을 검증한다.
