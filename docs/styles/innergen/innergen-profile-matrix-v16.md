# 이너젠·이너캐리 장표 프로필 매트릭스 v16 (2026-10-13)

다른 사용자의 Claude·Codex가 이 저장소로 같은 품질의 장표를 만들도록, **스타일 계열 × 업무 성격 × 보고 단계 × 전달 방식** 네 가지 선택으로 구성·화면·글자 크기·필수 장표를 정한다. 기계용 값은 [innergen-profiles-v16.json](innergen-profiles-v16.json), 차트·구조 장표·공신력 있는 출처 규칙은 [innergen-evidence-charts-v16.md](innergen-evidence-charts-v16.md), 재사용 요청문은 [prompt-v16.md](prompt-v16.md)에 둔다.

v16은 기존 v2–v15와 [report-profiles.json](report-profiles.json)을 대체하지 않고 상위 선택표로 묶는다. 기존 문서의 의미·근거·줄바꿈 규칙은 그대로 적용되며, 글자 크기는 §5 표가 전달 방식별 기본값을 정한다. 현재 사용자의 지시와 프로젝트 `spec_lock.md`가 항상 우선한다.

## 1. 선택 순서

| 단계 | 결정 | 기록 위치 |
|---|---|---|
| ① 스타일 계열 | 이너젠 보고서 / 이너젠 소개자료(v4.2 블루) / 이너캐리 | `design_spec.md` 개요, `spec_lock.md` `visual_style` 메모 |
| ② 업무 성격 | CDP·기후공시, 규제 대응, 감축사업·상쇄, 인벤토리, LCA·제품탄소, 기후리스크·시나리오, ESG 평가 대응, 기후·ESG 교육, 기후테크·소셜벤처 | `design_spec.md` `innergen_business_type` |
| ③ 보고 단계 | 제안, 착수, 중간, 최종, 교육·워크숍, 경영진 브리핑 | `design_spec.md` `innergen_report_type` |
| ④ 전달 방식 | 발표형, 교육형(강의), 교육형(배포 교재), 제안형, 보고형(읽기용) | `design_spec.md` `delivery_mode`, 글자 크기는 `spec_lock.md` |

요청에서 바로 판단되면 묻지 않고 기록한다. 판단이 갈리는 항목만 실행 경로의 확인 단계에서 한 번에 묻는다. 기존 Confirm UI의 `innergen_business_type`·`innergen_report_type`·`innergen_variant` ID(`cdp_disclosure`, `reduction`, `regulatory`, `inventory` / `proposal`, `kickoff`, `interim`, `final`)는 그대로 쓰고, v16에서 추가한 ID는 같은 칸에 문자열로 기록한다.

## 2. 스타일 계열

| 계열 | 이렇게 요청하면 | 화면·자산 | 기본 용도 |
|---|---|---|---|
| **이너젠 보고서** | "이너젠 스타일", "이너젠 보고서", "컨설팅 보고서" | `ppt139` 13:9. 덱 템플릿 `templates/decks/innergen/` (격자형·단색 남색형·슬림라인형 중 하나). 남색 `#0F243F`·흰색·회색, 빨강은 의미 강조만 | 고객 컨설팅 산출물: 착수·중간·최종 보고, 입찰형 제안서 |
| **이너젠 소개자료(v4.2 블루)** | "이너젠 소개자료 스타일", "이너젠 강의자료", "교육 자료를 이너젠으로" | `ppt139` 13:9. 덱 템플릿 `templates/decks/innergen_lecture/` (10개 레이아웃). 딥 네이비 `#0B1739`·블루 `#2F62F0`·거버닝 박스 `#F3F6FF` | 대학 특강·사내 교육·세미나·회사 소개·발표형 제안 |
| **이너캐리** | "이너캐리 스타일", "이너캐리 소개" | `ppt43` 1024×768 기본. 브랜드 `templates/brands/innercarry/`(정체성만, 레이아웃 템플릿 없음). `product-story`·`dark-opening`·`service-evidence` | 이너캐리 제품 소개, SaaS 도입 제안, 데모·영업 자료 |

- 세 계열 모두 SVG 작성 경로는 **Pretendard** 하나로 쓴다(저장소 글꼴 잠금, `CLAUDE.md`). 기존 원본 PPTX를 그대로 고치는 direct-PPTX 경로만 원본 글꼴을 보존한다.
- 한 덱에서 계열을 섞지 않는다. 이너젠 보고서 안에 이너캐리 제품 장표가 필요하면 이너젠 보고서 화면에 제품 화면 캡처만 근거로 넣는다.
- 템플릿을 고르면 실행 경로의 Step 3에서 템플릿 경로를 명시해 복사한다. 스타일 이름만으로 템플릿이 자동 선택되지는 않으므로 요청에 계열 이름을 쓰면 실행자가 이 표로 경로를 정한다.

### 2.1 계열 선택 기준

| 상황 | 선택 |

## 4. 보고 단계별 장표 순서

괄호 안은 이너젠 소개자료 템플릿(`innergen_lecture`)의 레이아웃, 대괄호는 이너젠 보고서 템플릿(`innergen`)의 화면이다. 장수는 기본값이며 자료에 맞춰 조정한다.

| ID | 단계 | 장표 순서 | 기본 장수 | 반드시 들어갈 것 |
|---|---|---|---|---|
| `proposal` | 제안 | 표지(01) → 고객 과제·배경(03b) → 제도·시장 근거(03e) → 목표와 범위(03d) → 접근 방법(03g) → 세부 수행 내용(03a) → 산출물(03e) → 일정(03a·간트) → 수행 체계·인력(03d) → 이너젠 실적·차별점(03f) → 맺음(04) | 12–18 | 과제를 고객 언어로 1문장, 범위 안/밖, 산출물 목록, 일정, 필요 협조 |
| `kickoff` | 착수 | 표지 → 목차(02) → 목적·범위·기준(03b) → 세부 수행 계획(03g) → 자료 요청 목록(03e) → 역할·커뮤니케이션(03d) → 일정·마일스톤(03a) → 결정 필요 사항(03b) → 맺음 | 10–15 | 기준연도·경계·적용 기준, 자료 요청 항목과 기한, 담당자, 의사결정 안건 |
| `interim` | 중간 | 표지 → 요약(03f) → 진행 현황(03a·진행 막대) → 잠정 결과(03e) → 확인된 사실 vs 미확정(03d) → 이슈·리스크(03b) → 결정 요청(03b) → 다음 단계(03g) → 맺음 | 10–18 | 진행률 근거, 잠정 수치의 상태 표기(잠정·검증 전), 결정 요청 문장 |
| `final` | 최종 | 표지 → 요약(03f) → 목차(02) → 방법·기준(03g) → 결과(03e·03c 반복) → 검증·한계(03b) → 개선 과제·로드맵(03a·로드맵) → 인계 사항(03e) → 부록 → 맺음 | 20–40 | 결론 먼저, 결과마다 근거 출처·단위, 한계, 잔여 과제와 담당 |
| `education` | 교육·워크숍 | 표지 → 목차(02) → 장 구분(02 재사용) → 개념(03c) → 사실·수치(03e·03f) → 제도·절차(03g) → 사례(03d) → 질문·정리(03b) → 맺음 | 20–60 | 학습 목표, 장마다 핵심 정리, 최신 수치의 기준일, 질문 장표 |
| `briefing` | 경영진 브리핑·이사회 보고 | 표지 → 한 장 요약(03f) → 왜 지금인가(03e) → 선택지 비교(03d) → 권고안·비용(03b) → 결정 요청(03b) → 부록 | 5–8 | 결정해야 할 것 1문장, 선택지별 비용·효과·리스크, 권고 |

- 요약 장표는 결론 → 근거 3개 → 요청 순서다. 요약에 처음 나오는 수치는 본문에 같은 값·단위·출처로 다시 나와야 한다.
- 중간보고는 원본 레퍼런스가 없다([report-profiles.json](report-profiles.json) `reference_counts`). 위 순서는 **구성 제안**이며 원본 재현으로 주장하지 않는다.

- **교육형(강의) 거버닝 18pt**는 2026-10 서강대 특강 덱에서 사용자가 확정한 값이다. v15의 교육형 16.5pt는 배포 교재(읽기용)에 남긴다.
- 거버닝은 최대 2줄. 2줄이면 `<tspan x dy="32">`로 나누고 `data-pptx-preserve-line-breaks="true"`를 붙인다. 붙이지 않으면 PowerPoint가 다시 줄바꿈한다.
- 표·차트 안의 글자는 16px(12pt) 밑으로 내리지 않는다. 넘치면 장을 나누거나 부록으로 보낸다.
- 투사 자료(발표·강의·제안)는 문장을 줄이고 관계를 도식·차트로 보인다. 읽기용(교재·보고)은 조건·예외·근거를 문장으로 남긴다.

## 6. 장표 공통 문법

모든 계열·방식에서 같은 순서로 읽히게 한다.

1. **제목** — 분류·주제 명사구("K-ETS 4차 계획기간 할당"). 주장은 제목에 넣지 않는다.
2. **거버닝** — 명시적 주어 + 판단 + 근거/조건, ~입니다/합니다 체([v11](design-governing-v11.md)). 숫자가 핵심이면 숫자를 거버닝에 넣는다.
3. **근거 영역** — 표·차트·도식 하나가 거버닝을 증명한다. 차트에는 단위·기간·기준을 붙인다.
4. **결론 박스(선택)** — 그래서 무엇을 해야 하는지(실행·점검). 거버닝과 같은 말을 반복하지 않는다.
5. **출처** — `출처: 기관, 「자료명」(발간연월), 기준연도·단위`. 재가공했으면 "…를 바탕으로 이너젠 재구성".
