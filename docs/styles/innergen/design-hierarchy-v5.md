# 이너젠 장표의 번호·목차·상단 간격 v5

2026-10-01 추가 피드백을 반영한다. [v4 정보 위계·문체](design-hierarchy-v4.md)의 모든 규칙을 유지하고, 거버닝 크기·간격 및 목차 번호는 이 문서를 우선 적용한다.

## 제목과 목차

교육자료는 표지 다음인 **2페이지에 목차**를 배치한다. 본문의 순서와 의미에 따라 대주제 번호를 부여하고, 각 부제목에는 `대주제-세부 항목` 번호를 부여한다. 예: `3. 필수 항목 / 3-1. 거버넌스`. 표지와 목차 자체는 본문 장 번호에서 제외한다.

목차의 대주제·세부 항목 번호와 본문 제목의 번호는 완전히 일치해야 한다. 목차 오른쪽에는 실제 장표 페이지를 표시한다. 대주제 시작/종료 페이지, 총 페이지, 푸터 페이지도 목차 추가 이후의 순서로 갱신한다. 같은 대주제가 두 열로 이어지면 ‘계속’으로 표시하고 번호를 새로 시작하지 않는다. 숫자 부여를 본문 도식의 관계를 대체하는 카드 나열로 사용하지 않는다.

이번 KSSB 교육자료는 9개 대주제, 41개 세부 항목, 표지·목차를 포함한 43장이다. 기후 지표 대주제에 온실가스 세부 항목을 포함하고 실습·해설을 하나의 학습 실습 대주제로 연결한다. 이 개수는 이번 자료의 값이며 다음 자료에 그대로 복제하지 않는다.

## 거버닝과 본문 간격

상세 교육자료의 거버닝은 **실제 PPT 20pt**로 사용한다. 780×540pt / 1040×720px 화면에서는 26.666667px이다. 본문은 실제 14pt를 유지한다. 상단 제목은 24pt를 유지하고, 거버닝의 문체는 `~입니다/합니다`의 완결 문장이다.

거버닝을 제목 바로 아래에 붙이지 않는다. 남색 헤더의 하단과 첫 본문 구획의 상단 사이에서 **실제 글자의 위아래 여백을 균형 있게 배치**한다. 한 줄 메시지는 글꼴의 실제 상승·하강 폭을 고려하여 수직 중심을 잡고, 위아래 간격 차이는 4px 이내를 목표로 한다. 이번 자료의 일반 장표 기준선은 y126~135이며, 고정 숫자를 다른 화면에 자동 복제하지 않는다.

두 줄 거버닝은 전체 문단의 실제 높이로 계산하고 본문을 아래로 재배치한다. 글자 크기만 키워 보조 메시지·표·도식을 침범하지 않는다. 보조 메시지가 같은 공간을 사용하는 경우 본문 구획 안의 적절한 위치로 옮긴다. 목차처럼 테두리가 없는 본문은 첫 소제목의 실제 글자 상단을 기준으로 간격을 맞춘다.

## 검사

- 목차 세부 항목의 개수·번호·문구·실제 페이지와 본문 전체의 일대일 대조.
- 번호가 붙은 제목의 우측 로고 공간 침범 및 불필요한 줄바꿈 확인.
- 실제 PowerPoint 출력에서 거버닝 20pt, 본문 14pt, 위아래 간격 균형 확인.
- 본문·조건·예외·단위·출처의 변경 여부 대조. 위치·목차 변경 때문에 내용을 삭제하지 않음.
- v4의 명사형 본문, 최종 메시지, 단어 경계 줄바꿈, 표 가로·세로 가운데 정렬 규칙 유지.
