# 이너젠 13:9 교육자료 재현 프롬프트

제공된 문서마다 독립적인 교육용 PPTX와 PDF를 제작한다. `design_13x9.md`와 `design_13x9.json`을 디자인 입력으로 적용하고, 저장소의 라우팅 및 선택된 실행 워크플로를 따른다. 13:9와 장수·폰트는 현재 작업에서 확인된 사용자 선택을 우선한다.

먼저 원문의 목적·핵심 개념·적용 조건·예외·수치 사례·실무 증빙을 페이지별로 정리한다. 표지 다음 2페이지에 번호·학습 범위·쪽수로 목차를 만든다. 각 본문 페이지의 상단은 번호가 있는 메인 제목/부제, 아래는 옅은 박스의 거버닝 메시지, 다음은 구조화된 본문, 하단은 최종 메시지 박스와 문서명·PDF 페이지 출처로 구성한다.

모든 거버닝 메시지는 `기업은`, `담당자는`, `검토자는`처럼 명시적 주어로 시작한다. 주어–중요한 판단–적용 조건–준비 행동의 연결이 있는 한 문장으로 쓰고 `확인해야 합니다` 또는 `준비해야 합니다`로 마친다. 단편적 표어를 피하고 본문의 증거에 연결한다. 최종 메시지도 같은 문장체로 실무 준비나 반드시 기억할 조건을 짚는다.

표·도식 본문은 포함·제외·공시·검토·연결 등 명사형으로 마친다. 같은 비교축과 관계에 맞는 도식을 선택한다. 중요한 키워드는 볼드·파란 볼드, 특히 중요한 조건은 선택적으로 빨간 밑줄로 강조한다. 표는 가운데 정렬하고 동일 계층의 카드·박스 간격과 패딩을 통일한다.

실제 글꼴과 사용 가능한 폭을 먼저 측정한다. 단어 경계에서 필요한 최소 줄 수만 사용하고 단어 하나가 남는 줄·부자연스러운 여백·개체 침범을 수정한다. 조건부 문구와 숫자·단위·사례 전제를 지키고, 교육 예시를 고객 사실이나 새로운 공시 의무로 일반화하지 않는다. 조정 차이를 실제 배출 감축으로 표현하지 않는다.

원본을 보존한다. 내용·산술·출처·주어·글자 폭·표 정렬을 검사하고 실제 PowerPoint에서 전체 장표와 PDF를 렌더링하여 검토한다. 최종 버전의 PPTX·PDF·검증 기록을 함께 납품한다.
