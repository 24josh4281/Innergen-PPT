# 이너젠 교육자료 13:9 디자인 규칙

## 화면과 정보 위계

## 폰트·글쓰기

- IBM Plex Sans KR 사용, 필요한 경우 Malgun Gothic 대체를 기록한다. 이 자료의 확인값은 제목30px(22.5pt), 거버닝22px(16.5pt), 본문·표·최종18px(13.5pt), 출처12px(9pt)이다. 화면 픽셀과 PowerPoint 포인트를 혼동하지 않는다.
- 거버닝은 반드시 명시적 주어로 시작한다: 기업은 / 공시 담당자는 / 검토자는 / 산정 담당자는. 주어 → 판단·조건 → 대비할 행동의 한 문장으로 작성하고 `확인해야 합니다`, `준비해야 합니다`, `기억해야 합니다`로 끝낸다.
- 단편적 구호를 피한다. 본문에 근거가 있는 가장 중요한 결론과 적용 조건을 함께 짚는다. 본문에 없는 의무나 고객의 사실을 추가하지 않는다.
- 도식·표·카드의 본문은 포함, 제외, 검토, 세분화, 연결, 변경 등 명사형으로 마친다. 조건부 표현(가능·해당하는 경우·중요하면)을 임의로 삭제하지 않는다.
- 최종 메시지는 명시적 주어와 정중한 문장체로 작성한다. 담당자가 준비할 증거·검토할 오해·기억할 조건 중 핵심을 1–2줄로 제시한다.
- 핵심 용어·판단 결론은 볼드 또는 파란 볼드로 표시한다. 전체 문장을 과도하게 강조하지 않는다. 빨간 밑줄은 예외 조건·오해 방지 등에 선택적으로 쓴다.

## 구조·가독성

- 절차는 흐름도, 원인과 결과는 연결도, 상이한 조건은 같은 비교축의 표, 실무 판단은 질문–답–증빙 표로 구성한다. 관계가 없는 01·02·03 나열을 도식으로 포장하지 않는다.
- 표 제목과 셀을 가운데 정렬하고 일관된 행 높이·열 패딩·격자선을 사용한다. 세로 중앙 배치를 지향하되 2–4줄 내용의 실제 높이를 확인한다.
- 의미 단위를 옅은 박스나 테두리로 묶는다. 같은 레벨의 카드는 폭·패딩·간격을 통일한다. 흰 공간은 관계의 구분에 사용하고 단순 미배치로 남기지 않는다.
- 실제 글꼴과 셀·카드의 사용 가능 너비를 먼저 측정한다. 한 줄에 맞으면 한 줄로 유지한다. 필요한 경우 단어 경계에서 최소 줄 수로 나누고, 끝 단어만 남는 고립 줄을 피한다. 질문·항목 이름을 다른 셀과 한 문장처럼 합쳐 검사하지 않는다.
- 거버닝 두 줄의 기준선은120/148, 최종 두 줄은597/621. 줄바꿈을 PowerPoint에서 보존하도록 자리표시자 첫 tspan은 dy0, 다음은 dy28 또는24를 사용한다. 일반 본문은 독립 텍스트 요소로 줄을 배치한다.

## 교육 근거와 검증

- 출처는 문서명과 물리적 PDF 페이지로 표기한다. 표지·목차를 포함한 PDF 페이지 번호와 인쇄 쪽수를 혼용하지 않는다.
- 숫자·단위·기간·예외·사례 전제를 보존한다. `150만 MWh → 1,500,000MWh`와 같은 표기 변환은 기록하고 대조한다. 방법·경계 차이로 감소한 값을 실제 감축으로 표현하지 않는다.
- 원문 교육자료의 예시·분류·실무 권고를 새로운 확정 의무로 바꾸지 않는다. 과거 제도 비교·계수의 시점을 표시하고 실제 업무의 최신 권장값으로 제시하지 않는다.
- 페이지별 글자 폭·줄 높이 검사, 전체 SVG 품질 검사, 표 표시 문구 대조, 주어 검사, PPTX 구조 검사, 실제 PowerPoint PNG·PDF 렌더링과 전체 화면 검토를 실시한다. 원본은 보존하고 새 버전으로 산출한다.

실행 주체와 승인·검증 절차는 저장소의 선택된 프레젠테이션 워크플로를 따른다. 이 프로필은 디자인 입력이며 실행 절차를 대체하지 않는다.
