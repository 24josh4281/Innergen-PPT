# 이너젠 소개자료 v4.2 기반 교육자료 디자인 — v9

2026-10-03 사용자 요청: 첨부 소개자료의 키 컬러를 적용하되 기존 PPT의 메인 제목과 거버닝 메시지를 그대로 유지.

## 실제 참조와 적용 범위

- 참조: `(이너젠) 이너젠 및 이너캐리 소개 자료_260916_v4.2.pptx`
- 참조 20장 전수 렌더 및 네이티브 색상·글꼴 분석. 참조 원본은 수정하지 않음.
- 표지: 참조 1장의 딥 네이비 바탕, 흰색 큰 제목, 밝은 블루 보조 정보.
- 본문: 참조 3·5·13·14·18장의 흰색 배경, 블루 강조, 연한 블루 분석 박스, 얇은 회색 구분선.
- 소개자료의 서비스·규제 일정·고객 사례 문구는 교육자료의 내용 근거가 아님. 디자인만 참조.
- 기존 5개 교육자료의 장수·순서·번호·전체 문구·수치·단위·출처 보존. 제목과 거버닝은 재작성 금지.
- 기존 교육자료 13:9 캔버스 유지. 참조의 4:3 비율을 강제 적용해 표 너비·본문 12pt를 변경하지 않음.

## 글꼴·위계

실제 네이티브 PPTX의 한글·영문 글꼴을 모두 `IBM Plex Sans KR`로 지정. 설치 여부와 실제 PowerPoint 렌더 확인. 다른 PC에서 동일 재현하려면 같은 글꼴 필요.

| 역할 | PPT pt | SVG px |
|---|---:|---:|
| 메인 제목 | 24 | 32 |
| 거버닝 메시지 | 20 | 26.67 |
| 본문 소제목 | 14.5 | 19.33 |
| 본문·표·최종 메시지 | 12 | 16 |
| 출처 | 10 | 13.33 |
| 푸터 | 10.5 | 14 |
| 표지 제목 | 42 | 56 |

1. 상단 제목: `목차 번호. 메인 주제 / 부제 번호 부제목`, 명사형. 기존 문구 고정.
2. 거버닝: 본문 핵심·대비 사항을 짚는 `~해야 합니다` 등 완결된 교육 문장. 기존 문구 고정, 블루 볼드.
3. 본문: 관계·비교·단계·범위를 보여주는 표·도식. 명사형 종결, 핵심어 볼드.
4. 최종 메시지: 실행·준비 사항을 담는 1~2줄 완결 문장. 연블루 박스와 블루 왼쪽 선.
5. 출처: 문헌명과 물리적 PDF 페이지. 링크나 내부 파일 경로는 장표에 표시하지 않음.

## 간격과 편집성

- 캔버스 1040×720, 좌우 48px, 본문 174~552px.
- 구획 간격 16px, 박스 내부 24px, 원래 도식의 연결·방향 보존.
- 분석 카드: 모서리 5px, 경계 0.8px. 표 내부 셀은 기존 구조·가운데 정렬 보존.
- 헤더: 흰색 배경, 네이비 제목, 얇은 블루 상단 선. 넓은 남색 사선 배너 제거.
- 푸터: 흰색 배경, 얇은 회색 선, 작은 브랜드·페이지 번호. 넓은 남색 푸터 제거.
- 단어·의미 단위 줄바꿈, 한두 단어만 남는 고립 줄·텍스트 침범 방지.
- PPT 본문·도형·연결선은 편집 가능한 네이티브 개체. 한 장 전체를 이미지로 대체하지 않음.

## 검증

- 원본 PPTX의 페이지별 모든 텍스트와 새 PPTX 텍스트 순서 대조. 줄바꿈 직전 공백은 레이아웃 공백으로 별도 기록.
- 메인 제목·거버닝 메시지는 SVG 원문을 페이지별로 정확히 대조.
- 글자 크기별 네이티브 실행값을 원본과 비교: 본문 12pt 유지.
- Microsoft PowerPoint로 62장 PNG·PDF 렌더, 실제 PDF에서 모든 기대 문구와 화면 경계 확인.
- 색상·글꼴·문구와 원본 파일 해시 확인. 기존 v1 파일과 참조 원본 보존.
