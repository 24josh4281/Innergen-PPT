# 이너젠 구조화 PPT 재사용 프롬프트

이 작업 폴더에서는 저장된 이너젠 규칙과 함께 아래 요청을 사용한다.

```text
제공한 자료로 이너젠 스타일의 전문적인 구조화 PPT를 만들어줘.
독자와 목적: [교육 / 보고 / 제안, 대상 독자]
원자료: [경로 또는 내용]
재구성 범위: [장수·순서·문구 조정 가능 여부]

docs/styles/innergen/design.md, design.json, design-rules.md와
design-v2.md, design-v2.json과 최신 design-hierarchy-v4.md·json을 읽고 적용해.
이너젠의 화면 비율·남색 헤더와 푸터·흰 본문·회색 자료 구획·로고를 유지해.
글꼴과 확인된 글자 크기는 기존 규칙과 이번 사용자 설정을 따라.

먼저 교육/업무 흐름을 설계하고 상단 분류형 제목 / 부제목을 정해.
핵심 주장은 그 아래 ~입니다/합니다 체의 거버닝 한 문장으로 작성해.
구조화 본문은 명사형 마무리, 내용이 많으면 형식체 최종 메시지 박스를 넣어.
단어 경계에서 줄바꿈하고 표 셀은 가로·세로 가운데 정렬해.
내용에 따라 포함 관계, 인과, 분기, 비교, 순환, 담당별 절차,
시간축, 계층도를 골라 편집 가능한 도식으로 표현해.
번호 나열이나 동일한 세 칸 레이아웃을 전체에 반복하지 마.
화살표에는 실제 논리와 방향을 담고 필요한 조건을 표시해.

필수·선택·예외·금지·기간·단위·경계와 출처를 보존해.
원문 요구사항과 실무 해설·교육용 사례를 구분해.
자세한 설명은 별도 원고에 남기고, 통합한 주제와 장표의 대응표를 만들어.
원본과 이전 버전을 보존하고 새 버전으로 저장해.

PowerPoint와 PDF를 실제로 확인해 글자 누락·잘림·겹침·출처·편집성을 검사해.
색상만 꾸미는 수정에 그치지 않고 독자가 관계와 판단을 이해할 수 있게 완성해.
```
