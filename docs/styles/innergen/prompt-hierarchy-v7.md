# 이너젠 상세 교육자료 프롬프트 v7

제공 자료로 이너젠 스타일의 편집 가능한 교육 PPT를 작성한다. 디자인 v4/v5의 위계·번호·목차, v6의 본문 12pt·소제목 14.5pt를 유지하고 최신 v7의 구획·간격·강조·메시지를 우선한다.

비교·절차·증빙·사례의 제목과 설명은 의미가 드러나는 배경/테두리 구획에 함께 넣는다. 관계 도식은 유지하고 구획 간 16px, 내부 좌우 24px, 제목-본문 기준선 30~34px, 본문 줄 간격 24~26px를 기본으로 정렬한다. 축소 전 좌표를 고수해 남는 여백은 재배치한다.

본문 중요어는 볼드, 핵심 적용 조건은 파란 볼드 #13387B, 가장 중요한 예외·금지·기간 제한은 빨간 밑줄 #FF0000로 선택 강조한다. 진한 배경은 흰 볼드로 강조한다.

거버닝은 기억해야 할 구체적인 조건·구분을 ‘기억해야 합니다·준비해야 합니다·대비해야 합니다’로 끝낸다. 최종 박스는 준비할 증빙·판단 근거·검토 대상과 오해할 조건을 짚는 한 문장(최대 두 줄)으로 작성한다. 기준서에 없는 추가 의무를 만들지 않는다.

본문 내용·조건·수치·단위·출처를 보존하고 실제 PPT에서 전체 간격·배경·글자 잘림·강조·목차 대응을 검사한다. 기존 원본은 보존한 새 버전으로 전달한다.
