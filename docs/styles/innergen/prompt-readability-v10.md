# 이너젠 교육자료 v10 프롬프트

기존 이너젠 교육자료를 수정할 때 `design-readability-v10.md`와 같은 JSON을 최우선으로 적용하고, 소개자료 v4.2의 네이비·블루 색상을 유지한다.

거버닝 메시지는 문구와 20pt 크기를 유지하고, 더 옅은 블루 #F3F6FF 배경 박스와 얇은 #DFE7FF 외곽선을 넣는다. 좌우 기준선과 내부 여백을 본문에 맞추며 본문과 최소16px 간격을 확보한다.

본문·표·최종 메시지는 기존 12pt에서 14pt 이상, 본문 소제목은 14.5pt에서 16.5pt 이상으로 확대한다. 메인 제목 24pt와 출처·푸터 크기는 유지한다. 모든 글꼴은 네이티브 IBM Plex Sans KR로 지정한다.

내용·숫자·단위·기간·조건·출처·목차·장수·순서를 보존한다. 확대 후 여유 공간을 활용해 내부 여백·열 너비·단어 단위 줄바꿈을 조정하고 표는 가운데 정렬한다. 글자를 14pt 미만으로 되돌리지 않는다.

원본을 보존하고 새 버전 PPTX·PDF를 만든다. 실제 글꼴 너비 검사와 전 페이지 PowerPoint 렌더로 잘림·침범·불균등 여백을 확인하고, 문구 보존·글자 크기 변경·거버닝 박스 유무를 페이지별로 검증한다.
