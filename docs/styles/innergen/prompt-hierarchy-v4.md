# 이너젠 스타일 재사용 프롬프트 v4

```text
제공한 자료로 이너젠 스타일의 편집 가능한 PPT를 만들어줘.
docs/styles/innergen/design.json, design.md와 design-rules.md를 읽고,
최신 design-hierarchy-v4.md·json의 정보 위계와 문체를 우선 적용해.
상세 교육자료는 design-detailed-v3.md의 14pt 및 상세 요구사항 규칙도 함께 적용해.

남색 상단에는 메인 제목 / 부제목을 분류·주제 명사구로 작성해.
제목 아래 메인 거버닝은 본문 핵심을 요약한 한 문장으로,
~입니다/합니다 체로 작성하고 최대 2줄로 배치해.
그 아래에 보조 메시지 또는 의미에 맞는 구조·도식·표를 넣어.
본문 도식과 구조화 구획의 문구는 공시/통합/변경/검토 등 명사형으로 마무리해.
필수·선택, 적용 대상·기간, AND/OR 조건과 예외를 축약 과정에서 삭제하지 마.
내용이 많은 장표는 하단에 최종 메시지 박스 하나를 두고,
거버닝과 같은 문체의 실무 적용 문장 한 개를 1~2줄로 넣어.

단어 경계에서 줄바꿈하고 짧은 마지막 문장 꼬리만 남는 줄은 재배치해.
표는 머리글·본문·수치·단위를 가로·세로 가운데 정렬해.
긴 도식 설명은 왼쪽 정렬로 통일하고 동일한 패딩·행 간격을 유지해.
제목, 거버닝, 본문, 최종 메시지, 출처와 로고가 서로 침범하지 않게 해.
출처는 문서명과 페이지로만 표시해. 제공 PDF는 파일 페이지를 사용해.

본문만으로 실제 학습이 가능하도록 요구사항·조건·예외·증빙을 구체화해.
원자료 수치와 단위를 보존하고 원본 파일은 유지한 새 버전으로 저장해.
편집 가능한 PPT와 실제 PowerPoint 렌더 PDF를 검증한 후 제공해.
```
