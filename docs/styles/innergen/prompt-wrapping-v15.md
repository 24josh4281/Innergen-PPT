# 이너젠 줄바꿈·거버닝 크기 적용 프롬프트 — v15

[v15 작성 규칙](design-wrapping-v15.md)과 [JSON](design-wrapping-v15.json)을 적용한다. 현재 사용자 요청·확정 명세가 우선하며 원문·조건·예외·수치·단위는 보존한다.

거버닝 기본값은 교육형16.5pt(22px), 발표형20pt(26.67px)다. 본문은 교육형14pt(18.67px), 발표형18pt(24px)를 유지한다. 프로젝트 잠금값과 명시적인 SVG `font-size`를 함께 수정하고 각 텍스트에 선택 서체의 `font-family`를 명시한다.

줄을 나누기 전에 실제 설치 글꼴·굵기와 패널/셀의 안쪽 여백으로 전체 문장 폭을 측정한다. 한 줄에 들어가면 한 줄로 표시한다. 넘치면 사용 가능한 폭을 채우며 필요한 최소 줄 수로 배치하고, 조건절·복합 용어·어절의 경계를 보존한다. 두 줄 길이를 같게 만들려고 일찍 끊지 않는다. 짧은 종결부만 남으면 마지막 의미 묶음을 함께 옮긴다. 독립된 목록·비교축·AND 조건은 문장을 잇기 위해 합치지 않는다.

줄 수가 바뀐 박스는 실제 글자 높이로 수직 중심과 뒤의 요소 간격을 다시 정한다. PPTX·PDF에서 글자 크기·줄바꿈·잘림·목록 구분을 확인하고, 수정 전후 내용 일치와 원본 보존을 기록한 새 버전을 제공한다.

실제 내용 폭을 `data-pptx-text-width`에 기록할 수 있다. 충분한 폭을 먼저 사용해 검토한 의미 경계는 `data-pptx-preserve-line-breaks="true"`로 유지할 수 있다. 줄 유지 옵션을 조기 줄바꿈의 대안으로 사용하지 않는다.
