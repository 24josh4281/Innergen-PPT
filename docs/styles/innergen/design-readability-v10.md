# 이너젠 교육자료 가독성 규칙 — v10

2026-10-03 최신 사용자 피드백: 거버닝 메시지에 옅은 음영 박스 추가, 본문 글자 크기를 최소 2pt 확대.

이 규칙은 v4.2 소개자료 색상 프로필 v9와 함께 적용하며, 아래 글자 크기·거버닝 박스 규칙이 기존 12pt 규칙보다 우선한다. 이전 버전은 보존한다.

## 색상과 위계

- 흰색 본문, 딥 네이비 `#0B1739`, 블루 `#2F62F0`, 연블루 본문 박스 `#EEF2FF` 유지.
- 거버닝 배경: 본문보다 더 옅은 `#F3F6FF`, 얇은 `#DFE7FF` 외곽선, 모서리 5px.
- 거버닝 박스는 본문과 동일한 좌우 기준선 사용. 박스 내부 왼쪽 24px·오른쪽 최소 24px 확보.
- 메인 제목·거버닝 메시지의 문구는 그대로 유지. 거버닝은 기존 블루 볼드 20pt 유지.

## 글자 크기

| 역할 | 기존 | v10 | 증분 |
|---|---:|---:|---:|
| 본문·표·최종 메시지 | 12pt | **14pt** | +2pt |
| 본문 소제목 | 14.5pt | **16.5pt** | +2pt |
| 메인 제목 | 24pt | 24pt | 유지 |
| 거버닝 | 20pt | 20pt | 유지 |
| 출처 | 10pt | 10pt | 유지 |
| 푸터 | 10.5pt | 10.5pt | 유지 |

폰트는 네이티브 IBM Plex Sans KR. 표지의 큰 주제 제목·작은 브랜드 정보는 유지하고, 표지 학습 경로 본문·소제목·핵심 문장은 동일하게 +2pt.

## 공간 사용과 정렬

- 1040×720 교육자료 캔버스 유지.
- 거버닝 박스: x48, y98, 너비944, 높이60px. 본문 시작 y174와 16px 간격.
- 본문 14pt를 작게 되돌려 넘침을 해결하지 않는다. 같은 문구를 유지하면서 내부 여백·열 너비·단어 단위 줄바꿈·행 위치를 조정한다.
- 본문 박스 내부는 기본 24px. 긴 조건·목표 문장이 있으면 최소16px까지 줄여 가독성과 완전성을 함께 확보.
- 기존 표 가운데 정렬, 도식 관계, 볼드·파란 볼드·빨간 밑줄 의미를 보존.
- 최종 메시지 박스 높이60px, 출처 기준선654px. 본문·최종 메시지·출처가 겹치지 않도록 확인.
- 숫자·단위·기간·적용 조건·출처·목차 번호·페이지 순서는 보존.

## 검증

1. 실제 설치된 IBM Plex Sans KR 글꼴로 모든 문장의 확대 후 너비를 측정.
2. 페이지별 글자 크기를 원본과 대조: 본문 역할은 +2pt, 제목·거버닝·출처·푸터는 유지.
3. PowerPoint에서 전 페이지 PNG·PDF 렌더, 박스·셀 안의 텍스트와 여백 확인.
4. 문구·수치·출처·장수·순서를 원본과 대조하고 글자 누락과 화면 경계 침범 확인.
5. 원본 파일은 보존하고 새 버전 PPTX·PDF와 검토 결과를 제공.
