# 이너젠 구조화 장표 디자인 v2

2026-10-01 사용자의 보완 요청을 반영했다. 새 장표의 내용 구성에는 이 규칙을 우선 적용하고, 색상·화면·로고·글꼴은 기존 [design.md](design.md)와 [design.json](design.json)을 따른다. 현재 작업에서 확인된 글자 크기는 유지한다.

## 장표를 만들기 전에

각 장표의 핵심 주장, 이를 뒷받침하는 근거, 독자가 이해해야 할 관계를 먼저 적는다. 자료의 목차나 문단 번호를 곧바로 장표 수로 바꾸지 않는다. 중복을 통합할 권한이 있으면 하나의 판단이나 업무 과정 단위로 묶고, 자세한 조건은 별도 원고와 연결한다.

## 의미에 맞는 도식

| 설명하려는 관계 | 사용할 구조 | 보존할 의미 |
|---|---|---|
| 전체와 부분·적용 범위 | 포함 관계·경계도 | 범위 차이, 포함·제외 기준 |
| 원인과 결과 | 인과 흐름 | 중간 경로, 결과, 근거 |
| 조건에 따른 적용 | 분기와 조건 패널 | 예·아니오, 또는·모두, 예외 후 의무 |
| 서로 다른 개념 | 같은 비교 축의 병렬 구조 | 같은 기간·단위·차원, 필수·선택 구분 |
| 반복 관리 | 순환·환류 | 평가·실행·점검·변경의 연결 |
| 담당 간 인계 | 역할별 절차 | 책임 주체, 인계 정보, 승인 |
| 적용 시점·기간 | 시간축·기간 막대 | 기준일, 실제 간격, 기간 종료·계속 여부 |
| 분류와 하위 항목 | 계층도 | 공식 범주, 분류의 근거, 상하 관계 |

## 편집 규칙

- 최신 [v4](design-hierarchy-v4.md) 적용: 제목은 메인 제목 / 부제목의 분류·주제 명사구이며, 핵심 주장은 그 아래 ~입니다/합니다 체의 거버닝 문장으로 작성한다. 구조화 본문은 명사형 마무리.
- 모든 본문을 01·02·03의 동일한 세 칸으로 나누지 않는다. 항목 수와 배치는 내용 관계가 결정한다.
- 화살표는 인과·절차·의존·환류 중 실제 의미가 있을 때 사용한다. 필요한 분기 조건과 방향을 표시한다.
- 도형은 논리 관계를 설명하는 편집 가능한 직사각형·선으로 구성한다. 장식만을 위한 카드·사진·큰 숫자는 넣지 않는다.
- 상세 문장은 핵심 논리를 살려 정리한다. 중요한 적용 조건·단위·경계·출처를 삭제해 공간을 확보하지 않는다.
- 복잡한 내용은 장표 분할 또는 상세 원고로 연결한다. 확인된 본문 크기보다 줄이는 것을 우선 해결책으로 삼지 않는다.
- 숫자 차트와 행렬의 위치·임계값은 근거가 있을 때만 만든다. 개념적 배치를 측정 데이터처럼 제시하지 않는다.
- 규정의 필수·선택·금지·예외·기간을 구분한다. 실무 제안과 교육용 사례는 원문 요구사항과 구별하여 표시한다.

## 완료 기준

장표만 읽어도 무엇이 포함되고, 왜 연결되고, 언제 적용되는지 이해할 수 있어야 한다. 상세 원고에는 통합 전 주제와 출처를 추적할 수 있는 대응표를 둔다. 편집 가능한 PPT와 PDF를 대조해 글자 누락·잘림·겹침을 확인하고, 다른 PC의 글꼴 차이는 PDF로 보완한다.

이번 적용 예시는 [KSSB 구조화 교육 v2](../../../projects/20261001_kssb_2026_structured_v2/design_spec.md)이다. 이 예시의 KSSB 조건이나 연도를 다른 프로젝트의 내용으로 복사하지 않는다.
