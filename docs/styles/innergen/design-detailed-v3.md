# 이너젠 상세 교육자료 디자인 v3

2026-10-01 사용자 요청 반영: 장표 본문 자체로 실제 학습이 가능하도록 설명을 구체화하고 본문은 실제 PowerPoint 14pt로 작성한다. 기본 이너젠 색상·화면·로고는 design.md/design.json, 의미 구조는 design-v2.md/design-v2.json을 따른다. 이 프리셋은 상세 교육자료에 적용하며 다른 보고·제안 자료의 확인값은 해당 사용자 요청을 따른다.

## 글자 크기와 밀도

- 화면: 13:9, 실제 PPT 780×540pt, SVG 1040×720.
- 본문·판단사항·사례·확인사항: 실제 14pt = SVG 18.666667px.
- 장 제목: 실제 24pt = SVG 32px. 리드: 18pt = 24px. 소제목: 16.5pt = 22px.
- 출처: 10pt = SVG 13.333333px. 본문 줄간격: SVG 26~28px.
- 본문을 임의로 더 줄이지 않는다. 문장을 구체화하면서 중복을 제거하고 조건·기간·대상·방법을 표시한다.
- 문장별 줄바꿈이 교육상 의미가 있으면 native export에서 --no-merge를 사용하고 실제 PowerPoint 렌더로 확인한다.

## 장표 내용 계약

핵심 관계를 나타낸 도식에 요구사항·적용 조건·예외·실무 확인을 결합한다. 강사 원고에만 핵심 설명을 남기지 않는다. 장표별 핵심 질문에 대해 독자가 다음을 설명할 수 있어야 한다.

- 무엇을 공시하는가: 대상·범위·기간·단위·방법.
- 무엇이 달라지는가: 필수·선택·완화·예외와 예외 후에도 남는 설명.
- 무엇을 확인하는가: 필요한 자료·판단 근거·경계·비교정보·검토 기록.
- 업무에 어떻게 적용하는가: 원문 요구와 구분한 교육용 사례·확인 질문.

숫자·기간·법률상 적용 여부를 새로 추정하지 않는다. 같은 번호 세 칸을 반복하지 않고 포함·인과·분기·비교·환류·시간축·역할 연결을 실제 의미에 맞게 사용한다.

## 출처와 검사

출처는 문서명과 제공 PDF의 파일 페이지로만 표시한다. 예: `출처: 제1호 일반 요구사항, PDF 17~18쪽; 제2호 기후 관련 공시, PDF 13~14쪽`. 문단 번호·별도 원고 번호는 장표 출처에서 제외하며 근거 기록에는 보존할 수 있다.

원본·이전 버전을 보존하고 신규 버전으로 저장한다. 본문 실제 14pt, 편집 가능한 텍스트·도형, 출처 형식, PDF 전체 문장 보존, 잘림·겹침과 주제 대응을 확인한다. 전체 렌더와 밀도가 높은 대표 장표를 검토한 뒤 PPTX/PDF를 제공한다.
