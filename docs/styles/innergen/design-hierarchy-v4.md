# 이너젠 장표의 정보 위계와 문체 v4

사용자의 2026-10-01 피드백을 반영한 최신 규칙이다. 기존 색상·로고·규격은 유지한다. 제목을 핵심 주장으로 작성하던 이전 규칙보다 이 문서가 우선한다.

## 1. 필수 위계

| 위치 | 역할 | 문체·형식 |
|---|---|---|
| 남색 상단 | 메인 제목 / 부제목 | 분류·대상·세부 주제의 명사구. 예: `기후 공시 / 필수 항목 - (1) 시나리오 분석` |
| 제목 아래 | 메인 거버닝 메시지 | 본문에서 가장 중요한 판단 또는 전체 요약. `~입니다/합니다`로 끝나는 완결 문장 1개, 최대 2줄 |
| 다음 영역 | 보조 메시지 또는 구조·도식 | 독자가 조건·관계·차이를 이해하는 데 필요한 내용. 거버닝의 반복 금지 |
| 본문 도식·구조화 구획 | 요구사항·조건·증빙·절차 | 명사형 마무리: `공시`, `구분`, `통합`, `검토`, `변경`, `예외 적용`. `한다/합니다/이다`형 설명을 그대로 쌓지 않음 |
| 내용이 많은 장표의 하단 | 최종 메시지 박스 | 핵심 적용 행동을 종합한 한 문장, 1–2줄. 거버닝과 같은 `~입니다/합니다` 문체 |
| 최하단 | 출처와 푸터 | 출처는 문서명과 페이지. 사용자 제공 PDF는 파일 페이지 기준 |

제목은 ‘무엇을 다루는가’, 거버닝은 ‘그 내용에서 무엇이 중요한가’, 본문은 ‘조건과 근거가 무엇인가’, 최종 메시지는 ‘어떻게 적용하는가’를 담당한다. 제목에 결론을 넣거나 거버닝을 명사구로 끝내는 역할 혼용은 금지한다. 표지·섹션 구분 페이지는 용도에 맞게 간결하게 작성한다.

## 2. 교육자료 밀도

상세 교육자료의 본문은 실제 PPT 14pt를 유지한다. 13:9의 780×540pt 화면에서 1040×720 SVG의 18.666667px에 해당한다. 제목은 24pt, 거버닝은 18pt, 소제목은 16.5pt, 출처는 10pt를 기본으로 한다. 다른 용도에 14pt를 자동 적용하지 않는다.

명사형으로 바꿀 때 필수·선택, AND·OR 조건, 적용 대상, 기간, 제외 및 예외를 삭제하지 않는다. 예: ‘예상 재무영향에 한하여 역량·자원 부족 시 예외 적용’. 단어만 남겨 요구사항을 모호하게 만드는 축약 금지. 수치·단위·배출량·법적 조건은 원자료와 대조한다.

## 3. 줄바꿈과 여백

- 띄어쓰기 경계 또는 논리적으로 독립된 항목 사이에서 수동 줄바꿈. 한 단어·약어·수치와 단위·괄호 안 조건을 임의로 분리하지 않음.
- 연속 문장의 마지막 줄에 ‘공시’, ‘합니다’ 등 한 단어만 남지 않도록 앞의 2–3단어를 함께 이동하거나 의미를 유지한 문장 재작성.
- 연속 설명의 마지막 줄이 앞줄 폭의 35% 미만이면 재검토. 독립된 짧은 노드·행 제목은 예외이며 문장 꼬리와 구분.
- 텍스트가 길면 먼저 구획 폭·행수·패딩·문장을 조정. 글꼴 크기만 줄여 해결하지 않음.
- 본문 상자 내부 좌우 패딩 18–24px, 같은 역할의 시작선과 행 간격 통일. 제목·거버닝·본문·최종 박스·출처의 영역을 분리.
- 두 줄 거버닝은 본문을 아래로 재배치. 단순 줄바꿈으로 본문에 침범하지 않음.

## 4. 정렬과 구조

표의 머리글·본문·수치·단위 셀은 **가로·세로 가운데 정렬**을 기본으로 한다. 사용자 명시 지시가 있을 때만 예외 적용. 표 규칙을 긴 문단형 도식 설명에 기계적으로 적용하지 않으며, 긴 설명은 왼쪽 정렬로 통일한다. 짧은 도식 노드와 비교 헤더는 가운데 정렬을 활용한다.

도식은 인과·포함·분기·비교·환류·시간축 등 내용의 관계를 표현한다. 숫자 01·02·03을 붙인 카드 나열만으로 구조화를 대체하지 않는다. 연결선은 글자와 분리하고, 교차·침범·불균등 여백을 검사한다.

## 5. 출고 검사

전체 장표에 대해 제목/거버닝 역할, 형식체 종결, 명사형 본문, 조건 보존, 단어 경계 줄바꿈, 짧은 마지막 줄, 가운데 정렬 표, 상자 패딩, 로고 영역 침범, 출처를 확인한다. 편집 가능한 PPT로 출력한 뒤 실제 PowerPoint PDF·이미지로 전 장표를 검토한다. SVG에서만 이상이 없다는 이유로 출고하지 않는다.
