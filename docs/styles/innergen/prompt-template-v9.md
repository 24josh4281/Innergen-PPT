# 이너젠 소개자료 v4.2 컬러 적용 프롬프트

기존 교육용 PPT를 이너젠 소개자료 v4.2의 키 컬러와 위계로 재디자인한다.
`design-template-v9.md`와 `design-template-v9.json`을 함께 따른다.

메인 제목·거버닝 메시지는 원문 그대로 유지한다. 전체 본문, 최종 메시지, 출처, 목차 번호, 장수와 순서, 도식 관계, 숫자·단위를 보존한다. 소개자료의 회사·서비스·규제 일정 문구를 교육 내용에 가져오지 않는다.

딥 네이비 #0B1739, 블루 #2F62F0, 연블루 #EEF2FF, 본문 회색 #475569를 사용한다. 표지는 네이비 배경과 흰색 제목, 본문은 흰색 배경과 네이비 제목·블루 거버닝으로 구성한다. 넓은 사선 제목 띠와 남색 푸터는 얇은 구분선으로 바꾼다. 표·카드·도식은 기존 정보 관계를 보존하며 연블루 면과 일정한 여백으로 묶는다.

IBM Plex Sans KR을 네이티브 글꼴로 명시하고 본문·표·최종 문장은 12pt 유지한다. 중요한 핵심어의 볼드, 파란 볼드, 의미가 있는 빨간 밑줄을 유지한다. 단어 단위 줄바꿈과 표 중앙 정렬을 유지하고, 글자 잘림·침범·짧은 고립 줄을 확인한다.

원본을 수정하지 말고 `_템플릿_v2` 등 새 파일로 PPTX와 PDF를 만든다. 페이지별 제목·거버닝·본문·수치를 원본과 대조하고, 실제 PowerPoint 렌더로 모든 페이지를 확인한 뒤 결과와 남은 제약을 보고한다.
