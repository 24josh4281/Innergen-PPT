2026-10-25 사용자 요청. 적용 계열은 `innergen_business`(뉴비즈)와 `innergen_lecture`(교육·강의)이다. 후속 사용자 요청으로 교육자료까지 확대했다. 이너캐리는 변경하지 않는다. 현재 프로젝트 확정값과 사용자 지정은 우선한다.

## 1. 근거와 범위

- 사용자 첨부 `(주)이너젠_회사소개자료_260619_외부 발송용.pptx`의 7페이지와 첨부 화면을 기준으로 한다. 원본 XML에서 두 문단의 가운데 정렬(`ctr`), 연두 `A4C700`, 파랑 `4285F4`를 확인했다.
- 원본의 13페이지는 병렬 파트너십 근거, 17페이지는 조달 업무와 역할의 추가 구조 참고다. 전체 22페이지의 텍스트·색상 추출은 `OUTPUTS/20261025_newbiz_style_review/source-evidence.json`에 기록했다. 전체 페이지의 렌더 검수를 완료했다는 뜻은 아니다.
- 원본 문구·기관 로고·인원수·실적·날짜는 스타일 근거이지 새 장표의 사실이 아니다. 원본 파일은 수정하지 않는다.

## 2. 거버닝 메시지

| 요소 | 적용 규칙 |
|---|---|
| 정렬 | 본문 유효 폭의 가운데. 960×540px 기본 캔버스에서는 x=480, `text-anchor="middle"` |
| 기본 글자 | 검정 `#000000`, 기존 IBM Plex Sans KR Bold와 확정 크기 유지 |
| 중요 부분 | 핵심 판단·효과·행동을 나타내는 1–2개 어구만 연두 `#A4C700` Bold |
| 강조 단위 | 문장 전체가 아닌 의미가 완결되는 어구. 주어와 일반 연결어는 검정 |
| 줄 수 | 기존 한 줄 우선. 첨부 예시처럼 두 줄을 요청하거나 확정한 경우 각 줄을 가운데 정렬하고 거버닝 높이·본문 시작점을 함께 조정 |
| 빨강 | 기본 강조에 사용하지 않음. 실제 위험·주의·예외에만 사용 |
| 배경 | 흰 바탕. 문장 전체를 녹색 박스로 감싸지 않음 |

강조 어구를 별도 텍스트 상자로 띄우면 전체 중심이 어긋나기 쉽다. 한 텍스트 안의 런으로 표현한다. SVG 예시:

```xml
<text x="480" y="71" text-anchor="middle"
      font-family="IBM Plex Sans KR" font-size="21.33" font-weight="700" fill="#000000">검토 결과는 <tspan fill="#A4C700">핵심 판단과 근거</tspan>를 연결합니다</text>
```

`{{KEY_MESSAGE}}` 슬롯은 호환성을 위해 유지한다. 실제 문장을 넣을 때 위처럼 강조 런을 작성한다. 템플릿의 `data-governing-emphasis-color`는 작성 안내이며 글자에 색을 적용하는 기능이 아니다. 완성본에는 실제 `tspan fill` 또는 PowerPoint 텍스트 런 색이 있어야 한다. 연두색은 작은 본문에 쓰지 않고 굵은 거버닝·넓은 제목 띠에 제한한다.

## 3. 도식과 색의 역할

| 역할 | 색·형태 |
|---|---|
| 주요 역량·핵심 축 | 연두 `#A4C700` 제목 띠 |
| 협업·연계·두 번째 축 | 파랑 `#4285F4` 제목 띠 |
| 제목 띠 글자 | 흰색 Bold, 가로·세로 가운데 |
| 근거 패널 | 흰색, 얇은 회색 `#D9D9D9` 테두리, 직각 모서리 |
| 일반 본문 | 검정 또는 회색 `#595959`, 좌측 정렬 |
| 본문 핵심 근거 | 파랑 `#4285F4` Bold, 필요한 어구만 |
| 기존 브랜드 표식 | 제목 왼쪽 바 등의 파랑 `#518FFF` 유지 |
| 연결선 | 회색. 선후·인과·보고 관계가 실제 존재할 때만 연결 |

- **병렬 근거·역할 비교:** 같은 높이의 연두/파랑 제목 띠, 두 개의 근거 패널. `03d_content_dual.svg`를 기본으로 쓴다. 로고·증빙 영역과 설명 영역을 구분하며 현재 사용 가능한 자료만 삽입한다.
- **하위 근거가 여러 개인 경우:** 상위 분류 띠 아래 패널을 세로로 분할한다. 서로 독립된 기관·역량을 화살표로 연결하지 않는다.
- **절차·역할:** 단계는 일관된 파랑 계열, 중요한 결정·도착점만 연두색. 동일 단계마다 다른 장식색을 배정하지 않는다.
- **표·차트·진단:** 값·축·단위·범례를 보존한다. 긍정/부정·위험 등 기존 의미 색을 무조건 연두/파랑으로 치환하지 않는다.
- 기존 남색은 보조 계층에 사용할 수 있으나, 예시형 병렬 근거 도식의 기본 두 제목 띠를 모두 남색으로 만들지 않는다.

## 4. 적용 및 검증

1. 뉴비즈·교육 계열과 현재 프로젝트 확정값을 확인한다.
2. 문장을 작성하고 핵심 어구를 정한 뒤 실제 색 런을 적용한다.
3. 본문 관계에 따라 병렬·절차·표 구조를 선택하고 위 색 역할을 적용한다.
4. 전체 거버닝의 중심, 줄바꿈, 본문 침범, 글자 잘림을 확인한다.
5. 연두 강조 누락·전체 문장 색칠·기본 빨강 강조가 없는지 확인한다.
6. PowerPoint 출력에서는 문장과 강조 어구가 편집 가능한 텍스트인지 확인한다. 원본 추출 결과와 새 결과물 검증을 구분해 보고한다.

새 패키지를 빌드하면 이 문서와 갱신 템플릿·기본 잠금이 포함된다. 이미 고정된 2026-10-23 런타임은 원본을 유지하고 `innergen-package.md`의 현재 패키지 연결 규칙을 따른다. 기존 프로젝트를 일괄 변경하지 않는다.

도식 생성기의 입력 JSON에는 `"governing_emphasis": ["핵심 판단과 근거"]`처럼 거버닝에 정확히 한 번 등장하는 어구 1–2개를 지정한다. `content_diagrams.py`와 `report_diagrams.py`는 뉴비즈와 교육형에서 해당 어구를 편집 가능한 연두색 런으로 만든다. 지정하지 않은 과거 입력은 호환성을 유지하므로 새 완성본 검수에서 강조 누락을 확인한다.

## 5. 교육자료·패키지 예시 확장

교육형은 1040×720px(13:9), 거버닝 x=520, Pretendard를 유지한다. 기존 거버닝 전체 파랑 대신 검정 + 연두 핵심 어구를 사용한다. 2단 도식은 연두·파랑 제목 띠를 공통 적용하되 교육형의 제목·푸터·박스 위치는 유지한다. 패키지 `examples/`의 뉴비즈·교육 SVG와 PNG는 디자인 예시이며 실제 고객 자료가 아니다. 새 패키지는 갱신된 두 계열 템플릿과 규칙·생성기를 함께 포함한다.
