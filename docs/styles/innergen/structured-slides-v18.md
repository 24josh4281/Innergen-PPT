# 이너젠 구조화 장표 v18 (2026-10-13)

삼일PwC(EU CSRD 공시 대응, TNFD 표준 동향, 지속가능성 세미나), 삼정KPMG(호텔산업 트렌드, 디지털금융 이슈, KPMG 보고서), 딜로이트(보험업 CSRD 벤치마크, 딜로이트 안진의 한국환경산업기술원 ESG공시 지원사업 최종보고서) 레퍼런스 8건, 약 350쪽에서 **구조만** 추출해 이너젠 장표 문법으로 다시 만든 규칙이다. 원문 문장·수치·로고·브랜드 색은 옮기지 않았다. 레퍼런스는 `INPUTS/PPT 장표 참고(구조화)/`에 있다.

- 상위 기준: [v17 수치 기준](design-standard-v17.md)(계열·좌표·글자 크기), [v16 매트릭스](innergen-profile-matrix-v16.md)(업무·보고 단계), [근거·차트 v16](innergen-evidence-charts-v16.md)(차트 유형·출처). v18은 그 위에서 **구조 장표의 선택·배치·밀도·근거 표기**를 정한다.
- 13:9 교육·강의(블루) 계열은 덱 템플릿 `templates/decks/innergen_lecture/`의 `s01–s20` 레이아웃으로 바로 쓴다. 다른 계열은 §5의 비율 규칙으로 같은 구조를 다시 배치한다.
- 기계용 값: [structured-slides-v18.json](structured-slides-v18.json). 선택 화면 구조 목록은 `design-standard-v17.json`의 `layouts`에 함께 등록했다.

## 1. 공통 원칙 (세 회사에서 반복 확인)

| # | 원칙 | 적용 |
|---|---|---|
| 1 | 제목은 주제, 거버닝은 결론, 본문은 증거 | 제목 명사구 → 거버닝 박스 1–2줄 결론(주어·수치 포함) → 구조물은 그 결론만 증명. 본문 안에 결론을 다시 쓰지 않는다 |
| 2 | 전시물 제목 레일 | 구조물 위에 `2px 남색 선 + 굵은 전시물 제목 + 1px 선`(높이 32px). 좌우 분할이면 두 레일의 높이를 맞춘다. 전시물 제목 ≠ 장 제목 |
| 3 | 마지막 줄 결론 | 구조물 아래 전폭 결론 바(높이 48–72px, 1줄 40자 이내). 거버닝 = 주장, 결론 바 = 다음 행동·함의 |
| 4 | 증거 2/3 : 해석 1/3 | 차트·표 장표는 오른쪽 1/3에 "시사점" 열을 둔다(첫 문장 굵게). 증거 안에는 해석을 넣지 않는다 |
| 5 | 한 색의 명도로 순서를 | 단계·기간·강도처럼 순서가 있는 것은 블루 명도 3–5단계(`#DFE7FF → #B8CBF9 → #7B9BF7 → #2F62F0 → #0B1739`). 병렬 항목은 같은 색·같은 모양 + 번호만 |
| 6 | 사실은 무채, 판단은 블루 | 현행·기존 기준·As-is는 회색/연청, 목표·개선·시사점·결론은 블루. 왼쪽→오른쪽으로 색이 짙어지면 결론에 가까워진다 |
| 7 | 강조는 한 곳 | 하이라이트(진한 칸·강조 행·점선 프레임·halo)는 장당 1곳, 많아야 2곳. 강조 대상 = 거버닝이 말한 대상 |
| 8 | 왼쪽 라벨 열 고정 | 매트릭스는 왼쪽 라벨 열을 본문 폭의 12–15%로 두고 연청 채움·굵게. 2단 계층이면 남색(대분류) + 연청(소분류) |
| 9 | 번호는 한 가지 기호로 | 원형 배지(카드·체크), 사각 태그(하위 항목), 큰 연한 숫자(전략 방향) 중 장표 역할별로 하나. 거버닝의 ①②③ = 패널 번호 |
| 10 | 표 위계 | 헤더 남색 채움·흰 글자, 첫 열 연청·가운데, 숫자 오른쪽 정렬·천 단위 쉼표, 결측 `–`, 파생값(증감률) 열은 회색 바탕, '우리' 행만 강조 |
| 11 | 차트 단독 금지 | 차트 옆(시사점 열)·아래(해설 띠)·위(가정 패널) 중 하나와 짝. 막대는 단색 + 강조 막대 1개, 값 직접 라벨, 격자선 생략, 계열 구분은 실선/점선 |
| 12 | 표본과 단위 | 비율 차트는 차트 안에 `n=○개 기업, 기준 시점`, 축 제목에 "% 의 모집단"(예: 기업 비율 %)을 쓴다. 평균에는 [최소;최대] 범위를 붙인다 |
| 13 | 출처 3층 | ①본문 위첨자 각주(정의·예외) ②표마다 `(단위: )` 우상단 + `자료: 기관(연도)` ③장 하단 출처 줄에 원자료와 "이너젠 분석"을 구분. 예시 수치는 `예시` 표기 |
| 14 | 전후 비교는 배치 고정 | 현황/개선안은 같은 자리에 같은 요소를 두고 바뀐 곳만 색칠 |
| 15 | 연결 장치는 의미가 있을 때만 | 깔때기(표→효과), 셰브론(단계), 확대 쐐기(목록→상세), 리더선(근거). 병렬 항목 사이에 화살표를 넣지 않는다 |
| 16 | 시리즈는 위치 고정 | 같은 구조를 여러 장 반복하면 레일·열 폭·결론 바 위치를 픽셀 단위로 고정해 바뀐 내용만 보이게 |

## 6. 완료 전 점검

- 거버닝 결론과 강조 대상(진한 칸·강조 행·점선)이 같은가
- 차트마다 단위·기간·표본(n)·출처가 차트 근처에 있는가
- 칸 글자가 16px 이상이고 칸 밖으로 넘치지 않는가(렌더로 확인)
- 같은 질문의 장표가 같은 구조·색·위치를 쓰는가
- 예시 수치에 `예시` 표기를 했는가, 이전 고객 자료가 없는가
- 선택한 실행 경로의 검사(`svg_quality_checker`, `verify_deck`)를 통과했는가
