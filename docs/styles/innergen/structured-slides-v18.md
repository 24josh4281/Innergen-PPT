# 이너젠 구조화 장표 v18 (2026-10-13)

삼일PwC(EU CSRD 공시 대응, TNFD 표준 동향, 지속가능성 세미나), 삼정KPMG(호텔산업 트렌드, 디지털금융 이슈, KPMG 보고서), 딜로이트(보험업 CSRD 벤치마크, 딜로이트 안진의 한국환경산업기술원 ESG공시 지원사업 최종보고서) 레퍼런스 8건, 약 350쪽에서 **구조만** 추출해 이너젠 장표 문법으로 다시 만든 규칙이다. 원문 문장·수치·로고·브랜드 색은 옮기지 않았다. 레퍼런스는 `INPUTS/PPT 장표 참고(구조화)/`에 있다.

- 상위 기준: [v17 수치 기준](design-standard-v17.md)(계열·좌표·글자 크기), [v16 매트릭스](innergen-profile-matrix-v16.md)(업무·보고 단계), [근거·차트 v16](innergen-evidence-charts-v16.md)(차트 유형·출처). v18은 그 위에서 **구조 장표의 선택·배치·밀도·근거 표기**를 정한다.
- 13:9 교육·강의(블루) 계열은 덱 템플릿 `templates/decks/innergen_lecture/`의 `s01–s20` 레이아웃으로 바로 쓴다. 다른 계열은 §5의 비율 규칙으로 같은 구조를 다시 배치한다.
- 기계용 값: [structured-slides-v18.json](structured-slides-v18.json). 선택 화면 구조 목록은 `design-standard-v17.json`의 `layouts`에 함께 등록했다.

## 1. 공통 원칙 (세 회사에서 반복 확인)

| # | 원칙 | 적용 |

| 3 | 마지막 줄 결론 | 구조물 아래 전폭 결론 바(높이 48–72px, 1줄 40자 이내). 거버닝 = 주장, 결론 바 = 다음 행동·함의 |

## 4. 업무 × 보고 단계 추천

선택 화면은 보고 단계 추천 2개 + 업무 추천 1개를 먼저 보여 준다(`recommended_by_report`, `recommended_by_business`). 같은 덱 안에서 구조 유형은 5–8종으로 제한하고, 같은 질문에는 같은 구조를 반복한다.

| 보고 단계 | 기본 흐름 |
|---|---|
| 제안 | 과업 구조도 → 단계별 로드맵 → 결론+근거 → (업무별 증거 장표) → 기대효과(현행→개선→효과) |
| 착수 | 과업 구조도 → 세로 단계 흐름 → 주체별 실행 체크(자료 요청) → 단계별 로드맵 |
| 중간 | 진행·이슈·조치 → 성숙도 히트맵 → 주체별 실행 체크(결정 요청) |
| 최종 | 핵심 요약 카드 → 차트+시사점 / 차트+표 → 발견↔시사점 → 질문+전략 방향 |
| 교육 | 질문형 키워드 지도 → 연도별 연혁 → 적용 시기표·판단 트리 → 자가진단 |
| 브리핑 | 핵심 요약 카드 → 기준 비교+시사점 → 질문+전략 방향 |

| 업무 | 우선 구조 |
|---|---|
| CDP·기후공시 | 성숙도 히트맵, 원칙+기준 매트릭스, 요구사항·진단표, 기준 비교+시사점 |

## 6. 완료 전 점검

- 거버닝 결론과 강조 대상(진한 칸·강조 행·점선)이 같은가
- 차트마다 단위·기간·표본(n)·출처가 차트 근처에 있는가
- 칸 글자가 16px 이상이고 칸 밖으로 넘치지 않는가(렌더로 확인)
- 같은 질문의 장표가 같은 구조·색·위치를 쓰는가
- 예시 수치에 `예시` 표기를 했는가, 이전 고객 자료가 없는가
- 선택한 실행 경로의 검사(`svg_quality_checker`, `verify_deck`)를 통과했는가
