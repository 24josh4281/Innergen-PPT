# 이너젠 상세 교육자료 본문 글꼴 v6

2026-10-01 최신 요청: 본문 내용의 글꼴 크기를 전체적으로 2pt 축소한다.
이 규칙은 [v5](design-hierarchy-v5.md)의 상세 교육자료 크기만 갱신한다.
정보 위계·문체·구조·번호·2페이지 목차·거버닝 간격 규칙은 그대로 적용한다.

| 구분 | 기존 | 적용 | 1040×720 SVG 값 |
|---|---:|---:|---:|
| 본문·표·도식·설명·최종 메시지 | 14pt | 12pt | 16px |
| 본문 소제목·목차 대주제·표지 과정명 | 16.5pt | 14.5pt | 19.333333px |
| 목차 장별 페이지 범위 | 12pt | 10pt | 13.333333px |

상단 제목 24pt, 거버닝 20pt, 출처 10pt, 푸터·페이지 표시와 표지 제목·상단 표제는 유지한다.
기존 장표 수정에서는 모든 문구·수치·조건·도형·좌표·줄바꿈을 보존하고 새 버전으로 저장한다.
다른 목적의 발표 자료에 자동 적용하지 않으며, 현재 사용자의 별도 지정이 최우선이다.

검사: 전 장표 본문 크기, 제목/거버닝/출처 보존, 목차와 본문 번호·페이지 일치,
PowerPoint 실제 출력의 글자 잘림·표 밖 침범·내용 누락, 원본 보존을 확인한다.
