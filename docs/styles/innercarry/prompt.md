# 이너캐리 스타일 요청문

다음 문장을 새 발표자료 요청에 함께 사용할 수 있다.

> 이너캐리 스타일로 만들어 주세요. 현재 제공하는 사실·수치·날짜만 내용에 사용하고, `docs/styles/innercarry/design.md`, `design-rules.md`, `design.json`을 디자인 입력으로 적용해 주세요. 먼저 저장소의 발표자료 라우팅을 따르고, 규격·글자 크기·핵심 색은 해당 프로젝트 명세와 잠금 파일에 확정해 주세요. 원본 자료의 고객사 로고·화면·연락처·과거 규제 내용은 자동으로 재사용하지 마세요.

정확한 원본 PPTX 장표를 보존하며 문구만 채워야 한다면 현재 요청에 해당 원본 파일과 보존 조건을 명시한다. 이 경우 저장소의 네이티브 PPTX 경로가 적용된다.
