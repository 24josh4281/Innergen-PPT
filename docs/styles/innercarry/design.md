# 이너캐리 프레젠테이션 디자인

이 문서는 사용자 제공 PPTX의 관측값을 새 자료에 적용하기 위한 스타일 기준이다. 실행 값은 [`design.json`](design.json), 장표별 선택·검사는 [`design-rules.md`](design-rules.md), 원본 근거는 [`source-analysis.md`](source-analysis.md)에 둔다. 현재 사용자의 목적·자료·확정값이 우선한다.

## 1. 적용 범위와 변형

| 변형 | 기본 사용처 | 구성 |
|---|---|---|
| `product-story` 기본 | 이너캐리 제품·도입·효과 소개 | 흰 페이지, 남색~파랑 상단 선, 작은 PART 라벨, 큰 문장형 제목, 파란 키워드, 한 개의 주 도식 |
| `dark-opening` | 표지·큰 전환 | 남색 바탕, 파란 원형 질감·상단 선, 넓은 여백, 큰 흰 제목과 파란 핵심어 |
| `service-evidence` | 이너젠의 관련 역량·사례 | 정보가 많은 표·자료·로고 영역. 현재 자료의 증거만 배치하고 가독성 우선 |

P01과 P10–P28의 제품 이야기 구조를 기본으로 삼는다. P02–P09의 회사 소개 자료는 필요할 때만 `service-evidence`로 참조한다. 변형은 장표 역할에 따라 섞을 수 있지만, 색·글꼴·정렬 축은 한 덱에서 유지한다.

## 2. 화면과 레이아웃

| 항목 | 기본값 | 근거·적용 |
|---|---|---|
| 원본 PPTX | 1080×810 pt, 4:3 | 원본의 실제 물리 크기 |
| 새 SVG/PPT 작업 | `ppt43`, 1024×768 px | 저장소에서 지원하는 4:3 규격. 원본 좌표와 글자 크기를 그대로 옮기지 않음 |
| 16:9가 명시된 경우 | `ppt169`, 1280×720 px | 구성을 다시 배치하고 내용 밀도·글자 크기 검토 |
| 기본 여백 | 좌우 약 5.6%, 상단 PART 약 6.5% | 원본 x≈60/1080 pt, y≈52.5/810 pt의 비율을 참고한 제작 기본값 |
| 정렬 | 공통 좌측 축, 한 장의 핵심 메시지와 이를 지지하는 본문 | P11–P28 반복 관측 |

본문형에서는 상단 얇은 색 띠 → PART 라벨 → 제목 → 한 줄 요약·구분선 → 근거/제품 화면/도식 순으로 읽힌다. 여백을 빈 장식 카드로 채우지 않는다. 비교·타임라인·단계·제품 화면은 설명해야 할 관계가 있을 때만 사용한다.

## 3. 색상과 글꼴

| 역할 | HEX | 사용 |
|---|---|---|
| 구조 남색 | `#0B1739` | 어두운 표지·목차·수치 띠·제목 |
| 선명한 파랑 | `#2F62F0` | 중요한 단어, 진행 단계, 상단 선, 주 액션 |
| 연파랑 | `#7B9BF7` | 남색 위 보조 강조와 타임라인 |
| 흰색 | `#FFFFFF` | 본문 배경, 어두운 영역의 글자 |
| 옅은 표면 | `#F8FAFC`, `#EEF2FF` | 카드·선택 상태. 본문 전체에 과도하게 깔지 않음 |
| 본문 회색 | `#475569` | 본문·보조 설명 |
| 경계선 | `#E2E8F0` | 카드·표·구분선 |
| 위험 강조 | `#991B1B` | 위험의 뜻이 검증된 경우에만, 원본 P14에서 확인 |

본문 기본 글꼴은 **IBM Plex Sans KR**다. 표지의 `Noto Sans KR`와 영어 `Carry`의 `IBM Plex Serif`는 원본에서 확인한 선택적 처리다. 새 덱은 기본 글꼴 하나로 시작하고, 표지의 영문 단어만 의미가 있을 때 Serif로 강조한다. 설치된 IBM Plex Sans KR와 Noto Sans KR를 확인했고, 다른 컴퓨터에서는 대체 글꼴로 줄바꿈이 변할 수 있다. PowerPoint 원본을 직접 채우는 경로에서는 원본 폰트를 보존한다.

## 4. 글자 위계와 내용

| 역할 | 원본 관측 예 | 새 SVG 기본값 |
|---|---:|---:|
| 표지 제목 | P01 66 pt | 58–64 px |
| 본문 장표 제목 | P11 39 pt, P18·P21 33 pt | 30–36 px |
| PART 라벨 | P10·P11 9 pt | 11–12 px |
| 리드 문장 | 여러 크기 혼재 | 17–20 px |
| 본문·카드 설명 | 주로 10–16 pt | 16–18 px |
| 근거·주석 | 원본에 작은 글씨 혼재 | 12–14 px, 읽히지 않으면 분리 |

새 SVG의 `px`는 원본 PPT의 `pt`와 다른 단위다. 위 실행값은 1024×768 화면에 맞춘 기본 제안이며, 확인 화면이나 사용자가 확정한 크기를 덮어쓰지 않는다. 숫자·기간·고객 성과를 강조할 때는 출처와 단위를 함께 제시한다. 제목은 현재 장표의 주장이나 효익을 말하고, 자료는 그 주장에 필요한 근거만 싣는다.

## 5. 자산·적용 경계

표지의 파란 둥근 사각형은 원본의 장식 그림이다. `INNerCarry` 표기는 편집 가능한 텍스트와 이 사각형을 조합한 처리이며 독립된 공식 로고 파일로 확인되지 않았다. 이너젠 회사 로고, 고객사 로고, 제품 화면, 과거 연락처와 ESG·탄소 관련 숫자는 스타일 토큰이 아니다. 새 프로젝트에서 사용 권한과 최신성을 확인한 자료만 사용한다.

“이너캐리 스타일”은 디자인 입력을 선택한다. 프로젝트 `design_spec.md`와 `spec_lock.md`에는 확정한 색, 글꼴, 규격, 장표 구성을 따로 기록한다. 스타일 JSON 자체가 프로젝트 잠금 파일은 아니다. 명시적인 브랜드 작업공간 경로를 사용한다면 `.claude/skills/ppt-master/templates/brands/innercarry/`는 정체성만 제공하며, 이 문서의 레이아웃 규칙은 별도로 적용한다.
